# 验证

智能体准备验收覆盖：名称/目录保存后进入选择页、首项手动选项、六款真实图标、逐项安装/认证状态、需登录入口、重新检测、上一步与下一步、设置默认选择、项目独立选择和重启恢复。检测中或失败仍可手动继续；未就绪工具不可选择；保存时再次核对认证；并发检测迟到结果不能覆盖新一轮或用户选择。浏览器无原生桥接时明确提示桌面端要求，不能伪造本机检测。认证进程覆盖完成、取消、超时、代码输入与受限官方URL；凭据与原始输出不入盘、不入日志。适配器真实模型对话另行验收，不以已登录代替。入口为 `tests/agent-selection.test.mjs`；中英文及小窗口检查全部七项、固定页脚、独立滚动与按钮文字边界。


CodeBuddy覆盖官方npm发行文件核验、Node版本、SDK认证探测、加密信封不误判就绪、受控终端官方登录、URL白名单、已有认证不重复登录、登录完成后新进程复查及token不进入返回值。安装覆盖锁定版本、仅官方源、关闭安装脚本、临时目录原子切换、失败保留旧版本、取消与错误脱敏；生产资源不依赖tmp。旧WorkBuddy/TRAE选择不复用身份，不显示TRAE选项。入口为`tests/codebuddy-install.test.mjs`及`tests/agent-selection.test.mjs`；真实安装和模型回复单独记录。

项目准备与列表验收覆盖：系统目录选择/取消、表单恢复、保存待规划草稿、重启后打开与修改、重名/保留名/非法路径/UTF-8长度、命令重试、旧修订冲突、目录缺失与重新定位、损坏或符号链接索引不丢原数据。草稿不提前创建用户项目目录，不伪造路线或进度；项目诊断不含名称、路径和书签。双语检查包括黑板创建页、居中白色半透明列表遮罩、标题“项目列表 / Project list”、列表无角色与缩略图、输入复合焦点及按钮文字不超出底板。名称覆盖15与16个中文/英文字素簇、组合字符和emoji：超出15个追加省略号，悬停及可访问名称保留全名，存储原值不变。进度与最近打开有独立间距，不因长名称挤靠或重叠。每项保留项目名、学习进度、最近打开日期、打开和删除按钮，项目名也可点击；不增加搜索框或排序下拉。无真实路线显示“待规划”，审阅样例不能充作真实进度记录。契约见[项目草稿](../contracts/project-draft.schema.json)，自动化入口为 `tests/project-drafts.test.mjs`。

项目分页与删除验收检查固定表头/分页栏、中间区域独立滚动、当前/总页、上一页/下一页、每页5/10/20条切换、首尾页禁用、空列表以及删除当前页最后一项后的有效页回退；切页和修改每页条数后滚动归顶，长列表和200%文本缩放均不遮住操作。删除覆盖取消无修改、确认后索引原子移除、重启不恢复已移除记录、重复请求幂等、写入失败保留记录和现存项目文件完整不变；界面不能仅隐藏一行便声称完成持久化删除。

界面一致性按[界面规则](experience.md)验收：同语义按钮在主页、设置、账户、项目与弹窗使用同一轮廓和状态，分别检查正常、hover、按下、键盘焦点、禁用及减少动态效果；按钮文字完整位于底板安全范围，图标不挤偏文字。目录末端仅有文件夹图标。有效名称、空名称失焦、非法名称及修正后四种状态中，目录控件位置与尺寸偏差不超过1 CSS px，错误出现不改变表单滚动位置；中英文与200%文本缩放都须通过。木框与金属包角组合仅见于模态弹窗；场景素材和独立面板均做目视检查，新美术未经用户确认不登记为已采用。

## 本轮 harness 检查

运行 `python3 -B scripts/check_harness.py` 与 `python3 -B -m unittest discover -s tests -v`。

检查范围：本地文档引用、路线 Schema 与语义、Agent 能力登记、素材清单、哈希/许可/目录边界和 Skill 入口完整性。双语布局属于产品交互验收；harness 检查不证明 GUI、Agent、license 或同步已可用。

## 账号增量

- `npm run build` 验证真实前端类型与构建，`npm test` 验证授权事务、签名、管理员输出、权限与失败恢复。
- 云端读回集合与 ADMINONLY 权限、平台函数调用规则、邮箱配置；通过正式 SDK 使用合成账号验证登录、激活、绑定、续租、解绑与重新绑定。
- macOS 包验证架构、签名、同包资源与当前前端一致，主入口只加载本机页面；验证导航与桥拒绝远程网页和其他端口，CloudBase前端发布被拒绝。实际打开窗口、进入/退出原生全屏、确认视频播放与设置可用。本地客户端另实测登录与云函数，不以公网前端结果替代。
- 注册邮箱收码、找回、改密及跨设备旧会话撤销由专用真实邮箱验证；合成账号密码登录不能代替邮件验收。新密码由用户亲自输入和提交。
- 验证首次发码、成功状态、倒计时、冷却结束重发、平台Retry-After、失败后重试与回调更新。用虚拟时钟及SDK替身验证完整API；界面验证确认密码即时反馈、修正后清除、无效时禁用提交及无验证码时仍显示不一致。发码接口接受请求不等于邮件已送达。
- 登录保持验证可信锚同一次开机有效期内冷启动零认证/身份/授权请求、跨7天静默滚动续期、access过期本地零请求、访问云端时按需刷新、授权缓存验签与到期、重启恢复、刷新轮换、主动退出/改密清除、失效会话清除、断网保留、运行时读写失败、加密文件损坏、密钥丢失、软链/硬链接拒绝、文件锁竞争、设备ID迁移、并发恢复和迟到刷新不复活。原生载荷验证环境、版本、大小与白名单；证明密码、令牌未进入浏览器存储、偏好和日志。SDK替身、真实文件跨进程读写、AES-GCM跨实现互通及真实App联调分别记录；目录0700、文件0600，未验证的Windows壳不标为已支持。
- 发码脚本的原码文件权限、不可覆盖与失败恢复须实测；代码、日志、网页包和二进制资源不得包含私钥、管理员凭据或原始激活码。
- 对照源v2验证随机安装身份与旧偏好迁移、输出目录迁移不覆盖现有运行数据；激活同事务首次绑定、新设备登录先确认再绑定、两席上限、同码重兑不延长、未预录签名码兑换、旧VI1及无token租约升级。验证token轮换与跨重启丢响应重试、本机解绑保留会话且部分失败/冷启动不回绑、腾出席位后可重新绑定、持续开窗执行7天静默检查与签名期限截止。
- 验证重新打包后使用同一运行目录恢复绑定和加密设备快照，同一次开机启动零请求，账户页可独立同步；首次绑定后列表含当前设备并落盘。覆盖旧六/八字段缓存迁移、跨账号/授权和重复记录拒绝、云端上限从2调大/调小后不重编译客户端即可同步并持久化。设备读取单飞、60秒复用、强制刷新、失败重试、旧列表保留、真实空列表与未加载状态、退出后迟到响应隔离均需覆盖；列表查询不触发bind/renew，不改变有效签名租约。

- 用模拟持续时钟验证系统日期回拨/前调、休眠跨七天、关闭App跨七天、同开机离线重启、电脑重启断网拒绝授权、联网续原绑定识别撤销、旧缓存升级、请求nonce及账号/产品/用途绑定、迟到签名响应不回退时间。原生时钟实测只读，不修改真实系统时间。验证过期时忙碌也失效，授权入口必须检查期限。

- 验证连续三轮周续期不再输入密码、六天逐日重启/前台/本地操作零请求、每轮一条原设备renew且不查询设备列表；离线超期在三次重试预算内保留刷新凭据并可自动恢复但不自动回绑撤销设备。验证SDK真实按需刷新、无access到期轮询、首次失败后1分钟/5分钟/15分钟三次后台恢复，耗尽清会话并弹出登录；认证、设备查询与续租共用预算，跨重启保留、并发不重复计数、联网事件不重置；成功清零且恢复周期调度。验证标准UUID认证标识跨启动稳定、安装间不同，SDK刷新缺失资料必须重新核对身份。真实合成账号验证两台登录并分别静默恢复、第三台能登录但无法授权，读回平台MaxDevice=50且License仍2席。

## 日志与翻译

- 按[日志规范](observability.md)验证固定字段与枚举，使用合成敏感值证明浏览器、原生、云端及内部读取内容均无身份、凭据、正文、路径、URL 或原始异常信息。
- 验证浏览器条数与字节上限、损坏输入、存储拒绝与内存降级；原生日志验证容量轮换、文件权限与链接防护，内部读取和清理仅面向开发诊断；写入失败不影响业务。用户设置与页面不显示日志分类、导出或清除控件。
- 认证映射覆盖SDK固定错误码、验证码发码/验码的阶段差异、域名、邮件配置、网络、限流和未知错误；通过实际API模块的SDK替身验证日志写入，不能只测映射函数。
- 使用合成账号实测错误密码登录、无效激活码及其云端关联；服务端记录与客户端的 `traceId / serverTraceId / clientTraceId` 须匹配，记录原因及阶段。真实邮件送达单独验收，不为制造故障修改共享认证配置。
- 验证新旧客户端请求兼容、非法 trace 拒绝、前后端 `clientTraceId` 关联；业务失败重试保留 `requestId`，更换诊断 ID，不改变幂等结果。
- 对 `zh-CN / en` 的主页、全部认证弹窗、设置及账户状态逐一验收，再检查英文扩展 40%、长中文、长连续字符串与 200% 文本缩放。按钮与正文换行撑高，窄屏滚动后操作仍可达；检查文字边界及实际交互，不能只看页面无横向滚动。
- 用户昵称、邮箱胶囊及项目列表名称可省略且须提供完整 title；项目名称另验收15字素簇边界及全名可访问性。其他翻译不能依赖隐藏 overflow 或缩小字号通过检查。

## 产品验收矩阵

H1 必须使用经验证的真实 Codex 完成背景访谈、路线生成/修订与采用、资料引用问答、笔记辅助和 Markdown 学习成果草稿。Mock 仅用于故障测试；导入与手动闭环仅证明降级可用，不能替代 AI 主流程验收。

H1 首页循环须通过真实播放与视觉审阅；动画样片不能替代 AI 验收。检查十轮接缝、角色一致性、举盾与火焰遮挡、持续播放、暂停、切页停止、独立标题与按钮叠加、双语布局及媒体失败后的静态操作路径。图生视频的首尾同图设置不等于循环已通过。

| 功能 | 必须验证的结果 |
| --- | --- |
| 路线 | 正确路线通过；空路线、未知版本、重复 ID、缺失依赖、自环、环、超限、额外字段拒绝；失败不改项目 |

| 同步 | 手机离线复习、重复事件、笔记冲突、配对撤销、删除传播、时区变化不丢数据 |

## 证据格式

每次验证在 `tmp/checks/<任务>/` 保存：命令/操作、版本与平台、输入、预期、结果、失败与限制。截图记录语言、视口和状态，不能用静态图证明交互或真实集成成功。

使用假时钟测试时间边界；授权测试使用隔离测试密钥与服务，不调用生产账号、支付或自动撤销真实设备。

- 新设备有空位时只显示绑定确认，取消后保留登录且不占位；关闭、手动检查、冷启动不自动绑定。满额不显示可确认绑定；腾出席位后再次询问，确认前容量变化由服务端拒绝超额。已有绑定不重复询问，激活仍为首次绑定原子事务。

- 账户兑换入口覆盖已激活与已到期状态；空码/空格禁止提交，处理中禁止重复提交与关闭。失败保留输入，取消/重开及切换账号清空；成功采用服务器返回的有效期和原设备信息，不在前端累加天数或保留激活码。中英文入口和弹窗文字不得越界。

- 验证授权到期、设备撤销、证书无效及首次登录后的授权校验失败均保留有效账号会话，同时`requireFeature`拒绝；重启不能复活无效授权。覆盖权益剩余不足5分钟时不连续续租、短租约有间隔、7天静默认证与三次网络失败退出仍有效。连续更新三版二进制后，运行目录及身份、成对加密会话、设置、项目、工具选择和日志原样保留。聚焦、输入、失焦及密码/目录复合控件均无黄色外圈，焦点以内层轻微加深表示，错误反馈仍可辨认。
