# 主页金丝熊抵挡龙焰循环动画

- 日期：2026-10-14
- 状态：方案可用，画质、编码和性能待样片验证
- 适用范围：H1 macOS 本地浏览器 GUI；以后可复用到网页端
- 调研问题：如何将参考图的低多边形伪 3D 场景做成金丝熊骑士举盾抵挡恶龙喷火的主页循环动画？

## 结论

**建议一期采用真实低多边形 3D 角色、骨骼绑定与 Blender 动画，离线渲染为不透明循环视频，主页用原生 video 播放，交互与文字用 DOM 排版。** 模型外形、拓扑、权重和姿态先验证，再制作完整周期。

分别准备金丝熊与恶龙的多角度中立姿态参考，生成模型候选，再用 Blender 完成骨骼、蒙皮权重、附件与同步动作。先做短片验证举盾与火焰接触。保留可编辑 .blend、模型、装备和动画；工具范围与绑定细节见[3D 制作调研](../rigged-3d-characters/2026-10-14.md)。

AI 图生视频可制作候选片，但是否保持角色外观、盾牌遮挡和连续动作需要逐帧实测。实时 Three.js 留给后续角色换装、镜头变化和互动场景；当前固定主页不要求实时 3D 引擎。以上为工程建议，不是已完成的画质或性能验证。

## 参考图与必要素材

参考图有森林、城堡、瀑布的远景，前景遮挡和柔和阴影；金丝熊位于左下，紫龙位于中右，右侧是菜单。参考只确定视觉方向，不证明素材的商业再分发权。

单张位图不包含角色被遮住的部分，也不包含张嘴、举盾和身体后倾的其他姿态。制作前需要清除图内按钮和文字、补全角色参考，并形成以下源素材：

| 层 | 最低要求 |
| --- | --- |
| 场景 | 无文字背景、地面、前景遮罩、角色接地阴影；保留菜单安全区 |
| 金丝熊 | 多视图参考、可变形角色模型与骨骼；独立剑盾、装备挂点与披风骨链 |
| 恶龙 | 多视图参考、四足骨架及颈/颚/翼/尾骨链；固定嘴部特效锚点 |
| 特效 | 具有体积感的火焰主体、少量火星、盾面暖光、地面反光；火焰终点随盾面移动 |
| 播放兜底 | 与视频同构图的静态 poster；无视频也能看懂页面并操作 |

角色参考可用图像工具生成或补画，模型可由图转 3D 形成候选。每个源文件需要独立检查形体、遮挡、权重与授权；模型生成成功不等于可以正确举盾或张嘴。

## 方法比较

下表是针对本场景的推断，成本为相对工作量，不是报价或工期承诺。

| 方法 | 动作与质感 | 循环与控制 | 制作投入 / 主页开销 | 建议用途 |
| --- | --- | --- | --- | --- |
| AI 图生视频 | 容易尝试完整画面；形体、接触关系和细节稳定性待试片 | 首尾帧可引导过渡；不能据此认定无缝或动作正确 | 初始投入较低，返工不确定 / 视频解码 | 视觉候选、快速验证气氛 |
| 分层图 + 姿态/网格 + 火焰合成 | 保留参考画风；适合固定视角、小幅动作；大幅转身需补姿态 | 锚点、遮罩与时间线可显式控制 | 中等，主要花在源素材 / 预渲染后视频解码 | 局部 2D 装饰 |
| Blender 低多边形建模、绑定、预渲染 | 深度、光照、遮挡与转身更可控；还原外形依赖建模质量 | 关键帧和周期曲线可控制，特效也需单独设计闭环 | 较高，需要模型/绑定/材质 / 视频解码 | 一期推荐制作方式 |
| Three.js 实时 GLB + 动画 + 特效 | 支持实时镜头、换装和交互 | 状态和时序可控，需处理渲染与资源生命周期 | 较高，还需性能与兼容调优 / 实时 GPU 渲染 | 后续互动与皮肤系统 |

事实依据：Firefly 官方提供图生视频首尾帧控制；GSAP Timeline 支持多对象时序；Blender 的 Cycles 修改器可重复动画曲线；Three.js AnimationMixer 可播放与管理动画。各工具的功能不等于本场景已经达到质量要求。[Firefly](https://helpx.adobe.com/firefly/web/work-with-audio-and-video/work-with-video/generate-videos-using-images.html)、[GSAP](https://gsap.com/docs/v3/GSAP/Timeline/)、[Blender](https://docs.blender.org/manual/en/5.1/editors/graph_editor/fcurves/modifiers.html)、[Three.js](https://threejs.org/docs/pages/AnimationMixer.html)。

PixiJS 的 ParticleContainer 适合轻量火星；它不能代替角色绑定和完整火焰设计，具体 API 与版本在试片时锁定。[官方说明](https://pixijs.com/8.x/guides/components/scene-objects/particle-container)。Spine 是可选骨骼工具，采用前需核对编辑器及运行时许可，本方案不把它设为必装依赖。[许可](https://us.esotericsoftware.com/spine-editor-license)。

## 推荐的制作与播放路径

1. 无文字构图、多视图与模型审阅：确定角色比例、盾牌朝向、龙口位置、喷火轨迹和菜单安全区，验证基础骨骼姿态。
2. 制作 2–3 秒抵挡动作测试：举盾到位、火焰撞击、身体受力和披风反馈。此片验证动作，不作为最终循环。
3. 制作约 8 秒完整周期：待机 → 蓄力举盾 → 喷火抵挡 → 火星消散 → 回到待机。
4. 将有限时长的 3D 场景渲染为帧序列，再编码视频；特效缓存与粒子可复现，检查首尾和渲染顺序不改变结果。
5. 导出 1080p 与 720p 候选视频和 poster，在真实主页验证循环、裁切、解码及按钮可用性。
6. 用户确认具体素材后，通过清单入库；生产主页只播放已确认视频，制作工具不成为用户运行依赖。

固定机位；火焰从龙口喷向盾面并在盾前扩散，盾后保持遮挡。金丝熊轻微后倾、腿部支撑，盾面与地面出现暖光；没有全屏震动、强闪烁或菜单覆盖。

无缝循环需要起止姿态、位置、光照和运动速度连续，火焰与残留粒子在边界消失或周期匹配。视频设置 loop 只会重复播放，不会自动修复接缝；不能用整段倒放代替收势，也不能仅凭第一帧等于最后一帧认定连续。实际文件需至少观看十轮循环。

## 播放、体积与兼容

推荐本地 H.264 MP4、不透明完整场景、无音轨；有收益且验证兼容后再提供 WebM。透明视频、GIF 和整场景精灵图集不作为一期默认交付格式。格式选择是本项目建议，实际解码、首帧和循环接缝仍需浏览器验证。

原生 video 提供 loop、muted、playsinline 和 poster；自动播放受浏览器策略影响，必须处理 play() 拒绝与媒体错误，保留静态画面及手动播放入口。[video](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video)、[自动播放](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)。

主页提供暂停控制，离开主页或标签隐藏时停止播放；用户主动暂停后不自动恢复。自动开始且超过五秒的装饰动画应允许暂停、停止或隐藏。[W3C](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)。减少动态效果或简化视觉时，在加载逻辑中直接选择 poster，不只用 CSS 隐藏仍在播放的视频。[减少动态效果](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)。

建议初始目标：8 秒、1920×1080 / 1280×720；自主制作母版 30 fps，AI 候选保留实际原生帧率。1080p ≤10 MiB、720p ≤5 MiB 是待编码验证的预算，不能通过明显模糊、变形或删掉抵挡动作达标。首次显示 poster 与按钮不等待视频；本地媒体由白名单提供，CSP 放行 media-src 'self'。
