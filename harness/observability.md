# 日志与诊断

## 数据边界

日志使用固定结构与白名单，只记录版本、UTC 时间、等级、事件、随机会话与操作 trace ID、固定操作名、失败阶段、耗时、结果码和授权状态。已识别的认证错误另外记录平台错误码/分类、数值错误号、HTTP状态、限流重试秒数和平台请求UUID；服务端对外统一错误另保留白名单 `causeCode` 以区分内部根因；未知文本不直接保存。仅保留白名单代码模块及行列号，不保留异常文本、完整堆栈或源路径。未知事件拒绝；未知错误归入固定通用代码。不记录邮箱、用户 ID、设备 ID、密码、验证码、激活码、token、私钥、资料正文、请求或响应正文、URL、文件路径及原始异常 message / stack。

记录账号操作、许可请求、后台续租、身份刷新、证书验证与全局异常。原生壳另记录启动、加载、本地服务与离线回退；失败不影响业务执行。客户端日志不自动远程上传，另以 `VI_DIAGNOSTIC ` 前缀输出同一脱敏结构到开发者控制台；界面不展示日志。

## 内部保存与读取

- 浏览器使用 `vibe-improve.diagnostics.v1` 保存脱敏环形日志，最多 300 条、256 KiB；读取时重新校验，损坏记录丢弃。存储不可用时仅保留内存记录。
- macOS 将日志保存到 `.app` 同级 `Vibe Improve Runtime/logs/`，每份不超过 1 MiB，保留当前及最近两份；目录权限 0700，文件 0600，拒绝符号链接与文件硬链接。
- 日志只用于内部运行诊断，不提供用户设置项、导出或清除界面。开发者可通过内部接口读取、序列化或清理已过滤的浏览器记录；原生桥只接收受信页面的白名单日志，不提供用户保存窗口或网页指定路径写入能力。
- 日志不是身份凭据、学习记录或授权证明，不能用于恢复会话或延长 license。

## 云端关联

云函数输出固定字段 JSON，不打印原始事件、身份上下文或异常。前端每次请求生成独立 `clientTraceId`，服务端校验 UUID 后剥离该字段，再校验业务请求；日志及响应回显该 ID，并生成服务端 `traceId`。旧客户端可不传 `clientTraceId`。

外层用户操作和内部认证/许可请求以 `parentTraceId` 关联；SDK调用分别记录登录、发码、验码、读取身份、刷新会话、退出等阶段。服务端响应的 `traceId` 作为客户端 `serverTraceId` 保存。

环境须开通 `Resources: ["log"]` 日志资源，按 `DescribeEnvs.LogServices.TopicId` 确认就绪。使用当前 `SearchClsLog` 接口检索，时间采用亚洲上海时区字符串。`node scripts/read-runtime-logs.mjs --client-trace <UUID>` 只返回经过二次白名单过滤的本应用记录，不输出平台原始日志。

云端日志按 `clientTraceId` 关联前端请求。诊断 ID 与业务幂等 `requestId` 分离；失败重试保留业务 ID，每次网络请求使用新诊断 ID。新增字段不改变 `ok / data / error`、授权判断或幂等语义。

验收要求见[验证](verification.md)。

## 认证错误

错误映射以锁定SDK错误码和当前官方认证接口为准。区分凭据拒绝、邮箱格式/已存在/未验证、账户状态、验证码错误/过期/平台未细分的错误或过期、密码策略、验证码次数/发码限流、二次认证、登录方式/客户端禁用、域名来源拒绝、邮件通道配置/投递失败、断网、超时和取消。平台未细分原因时保留其精度，不推断凭据是否属于某个真实账号。未识别错误保留已过滤的错误类型、状态、请求UUID和代码位置，标记为未映射，不伪造原因。

认证失败不进入许可云函数；以客户端阶段和平台请求UUID定位。激活失败通过客户端和云函数双端日志定位。

激活失败的对外错误保持统一，服务端内部原因区分激活码不存在、已使用、产品不匹配及记录损坏，不记录激活码或码哈希。平台请求UUID可能为v1，日志链路接受标准UUID v1–v8；客户端操作ID仍使用随机v4。
