# 内置规划提示词

本目录是 App 内置任务规则、响应契约和完整示例的唯一来源，源于 2026-11-04 审阅通过的统一规划方案。规则不按 provider 分支；生成时写入 Swift 常量，运行时不读取工作目录、用户文件或网络。

`interview / outline / lessons / review / consistency` 使用共同 envelope，`edit` 保留已有 `{reply,route}` 协议及 RouteV2 身份字段，以兼容现有编辑采用流程。公开 RouteV2 契约继续来自 `contracts/route.schema.json`；构建器只引用其可达定义，不另维护副本。

`planning.2` 在访谈同次判断中加入采用候选后的跨题一致性评估；独立 `consistency` 任务用于旧项目或采用同步建议后的生成前检查。输入使用已采用快照，保留本轮草稿作比较，不以草稿覆盖背景。非成功响应可提供结构化待复核事项；宿主核对目标题目、字段和实际快照，不从自然语言猜测。快照版本、事实哈希、epoch、采用事件与最终门禁由领域层管理，模型不生成这些可信元数据。旧访谈响应可缺一致性字段，届时须由宿主执行生成前检查。

修改 markdown、schema 或示例后运行 `node scripts/build-planning-prompts.mjs`。`--check` 校验生成文件未漂移。每个请求只包含当前任务可达 schema、当前任务示例，以及必要的共同规则。学习标准和充分性由 AI 按上下文判断，宿主只验证结构、引用、范围和用户采用。

构建器对可达契约执行受控词汇检查：未知校验关键字、未支持的类型、关键字值、非本地或缺失引用均阻止生成。新增校验能力时须同步 JavaScript 与 Swift 校验器并通过两者的共享用例；不能只在 schema 添加规则后让运行时忽略它。`$ref` 与同级约束共同生效。

示例仅使用合成数据。离线契约通过不等于模型遵循率、教学效果或新 CLI 集成已验证。
