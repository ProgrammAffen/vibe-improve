# 学习领域

## 访谈与路线

访谈以采集清单组织提升目标、用途与标准、当前基础、时间安排、范围与条件。目标明确成果、使用情境、成功条件与允许的帮助；标准可由AI协拟后用户确认。基础询问具体任务及独立或需提示的表现，区分自述、观察与推断，允许未知和拒绝短诊断。时间包含可持续每周预算及单次时段；期限区分硬性和可调整，按需补充长期使用、工具、实操、反馈、资料和限制。不收集无关身份信息，不做学习风格分类。

每项有必要字段和充分性条件；状态区分待采集、当前、待补充、待确认、待复核和完成。智能体只处理当前问题，提取信息并判定充分后生成回答总结；AI整理后明确询问“是否确认该回答？”，用户点击“确认回答”才标为已采集并进入下一项。新答复或修改均须重新总结和采用；含糊、矛盾或不完整回答继续补问。AI自行拟定的目标、标准和关键假设须经用户认可，不能凭空勾选完成；切换清单仅查看，不自动删除内容；可对选中的题点击“重新回答”，确认提示后清空该题及之后全部题目的回答、题内消息、快照、总结、证据和采用事件，从该题依次重新采集。之前的回答保留；取消提示不修改任何数据。统一“重新采集”经确认后清空五项回答、题内消息、待确认总结、已采用快照、采用事件、复核事项与可选资料说明，从提升目标重新开始；保留项目目录、名称、智能体及模型选择。已生成路线和编辑历史保留至新路线完整成功后替换。条件问题触发后才成为必要项，可选资料不计入完成门槛。必要项全部满足且没有活动判断或冲突时才启用“生成路线”，运行时按结构及版本复核，不以模型文字或前端勾选直接放行。

只追问会改变范围、起点、学习活动、预算、资源可行性或证据解释的信息；已回答不重复问，不覆盖用户修正。用户可跳过可选项、修正或转手动；未知只有在明确记录并接受相应降级规划方式时才满足该项，未回答不等于未知或不适用。时间未知时仅生成未排期结构草稿，未确认目标时不替用户选定成果。生成后仍进入章节编辑与用户审阅，不直接采用路线或开始学习。

先确定可以展示的结果与评价标准，再拆成大章节和小节点。每个节点有稳定 ID、目标、前置依赖和估计时间；目标用“能够完成什么”描述。小章节验收可省略；提供验收时必须包含练习任务、达标标准及对应目标引用；目标引用覆盖该小章全部学习目标，不重复、不遗漏。小节点默认适合一次学习时段，超过用户时间预算则拆分或提示。

生成提示词按教程组织知识进阶，而非项目管理任务清单：大章明确知识领域、关键概念和阶段能力；小章明确要学的概念或方法、练习步骤及可观察的掌握目标。AI生成或实质改写的小章均提供`activities`，具体描述学习示例、指导练习、独立尝试和反馈修正，按主题安排复现与应用。目标说明动作、对象、条件和成功表现，能合理量化时给出具体范围或检查，不凭空设置准确率、分数或保证成果。无正式验收也不能只写“理解基础”“掌握方法”等概括；验收仍可省略。已会工具不等于掌握原理，先修不明时安排小范围校准或补习。提示词在返回前自查知识覆盖、先修、练习对齐和时间可行性；运行时不以关键词判断教学质量。生成和AI修改共用教学要求，仅修改用户要求的内容，普通问答和未受影响章节保持不变。新提示词不自动重写已有路线。

大章节按能力阶段或任务复杂性组织，不因小章数量、篇幅或估时均匀拆并章节。生成采用路线v2：大章必填`stageGoal`，契约允许小章省略`activities`以兼容手动与导入路线，AI生成遵循上述教学要求；验收可选，定性验收须提供`evaluatorPrompt`。v1仍可导入，保留完整原始路线，升级草稿的大章目标留空，由用户填写或明确采用后才可确认，不静默丢字段。

AI 生成与导入路线使用同一 [路线契约](../contracts/route.schema.json)；运行时共用 [JavaScript校验器](../packages/domain/route-validation.mjs)，离线检查保留 [Python校验器](../scripts/validate_route.py) 并验证一致性。当前已实现访谈、生成与章节编辑；“确认路线”只记录通过严格校验的路线修订，不建立学习实例、地图或完成进度。导入不要求再调用AI。

## 已实现的规划流程

访谈、总纲和课批次共用[内置提示词包](../packages/planning-prompts/README.md)的核心规则、教学标准与任务契约，由AI结合当前题本轮对话和已采用答案判断是否足以规划。外层统一返回`status / reply / result / missing`；当前题结果包含`questionId / complete / summary / fields / evidence / unresolved`，运行时转换为既有领域格式。`ok`只表示本次任务有效，不表示用户已采用；`needs_input`与`cannot_complete`不能继续应用路线。识别自然同意、跨轮补充、定性标准、灵活时间和明确无条件；不按关键词、数字写法或逐字匹配判定。含糊、矛盾、未认可的建议继续澄清，关联冲突返回结构化待复核事项，不能静默改写其他已采用项。可选资料不阻塞；未知基础须认可合理起点，时间未知须认可相应安排。

`packages/domain/planning.mjs`管理五项清单、消息关联、请求修订及编辑草稿，[规划契约](../contracts/planning.schema.json)定义持久化结构。运行时按AI的结构化判断生成待确认总结，只复核格式、关联消息、空完成和修订，不再次解释回答；只有用户采用该版本总结才更新完成状态。采集值允许忠实归纳，`evidence.quote`为上下文依据说明，可转述；关联现存用户消息，采用建议时可关联更早的同项AI消息，不要求固定确认词。五项有效完成、无待复核事项、无活动请求，且当前背景拥有有效一致性检查记录时才允许生成。旧版v1原文依据、对话、清单与草稿原样兼容，不重置进度。

访谈消息关联仍保存完整规范ID；新请求仅给模型当前题本轮的`U1 / U2`用户消息与`A1 / A2`助手建议短引用，不暴露持久消息ID、requestId或`assistant_`编码。宿主按冻结映射将`messageRef / proposalRef`转换为真实消息关联；未知、角色错误、跨轮、跨题或晚于用户同意的建议拒绝，不靠补前缀猜测。既有领域层的旧编号兼容读取保留，不改写历史记录、不替用户作答或自动采用总结。

访谈同次返回当前候选的总结和跨题一致性评估，判断用户采用候选后的完整背景；共享语义规则区分冲突、待确认与兼容，不按关键词、主题数量或固定依赖表重置答案。当前修改是拟采用意图，已明确采用的变更是后续检查的意图依据；预算、设备、排除项和硬期限不得擅改，真实历史经验不改写成新领域经验，有意的多目标允许分阶段或分支。

用户采用总结时原子保存答案版本及对应评估。受影响题标为待复核，显示原值、原因和候选同步建议；用户可采用建议、稍后处理，从对应题重新回答并清空后续答案，或使用统一“重新采集”重做全部背景，无关答案继续有效。建议只合并指定字段，记录独立采用事件与来源，不伪造聊天消息或用户原话。采用建议后的最终背景由后续访谈或一次生成前检查验证，不能复用检查旧背景的结论。旧项目缺检查记录时首次生成补一次检查，原回答保留。

一致性凭据由宿主绑定策略版本、递增backgroundEpoch及规范化已采用答案/资料说明的SHA-256；模型不生成可信哈希或版本。采用候选的评估绑定基础epoch和完整候选事实，晚到、取消、重启恢复及A→B→A改动不能复用旧结果。前后端生成门禁共用领域层；焦点、模型或智能体切换不改变答案事实。生成阶段仍发现矛盾时以结构化问题回到同一复核界面，原路线与历史保留，不从回复文字猜测字段。技术失败保留草稿、已采用答案和旧路线，不自动重发。

采集页只显示当前题本轮的问答；切换清单只查看其他题；重新回答经提示确认后清空目标题及后续题，之前题目与可选资料说明保留；整轮重新采集删除本轮全部题内回答、对话和资料说明。两种操作均递增背景epoch，使旧总结及晚到任务失效。旧版已完成项原样保留，新回答统一走总结采用流程。必要项全部采用后由用户点击“生成路线”，每次点击都启动新生成，不复用旧路线。修改回答且已有章节时先提示“修改问题会覆盖已生成路线，是否修改？”，取消不启动请求；运行时再次校验覆盖许可与修订。新结果完整有效后才替换旧稿并进入编辑器，同时清除旧路线的编辑对话与章节引用，保留采集问答、答案快照及证据并重映射题目对话起点；失败、中断或取消保留旧路线与旧编辑对话。撤销路线不恢复已清除的旧对话。无AI直接空白编辑；导入直接编辑已有路线。未完成草稿可保存、重开继续，但确认时必须满足正式路线契约。手动保存、AI提案采用及路线替换共用撤销/前进历史，最多20个快照、合计2MiB；旧单步撤销记录可读取并在首次操作时纳入历史。撤销和前进均生成递增的路线修订，清除待采用提案与原确认状态；撤销后新建修改清空前进分支，无内容变化的保存不改变历史。未保存编辑在撤销时先保存为一个可前进恢复的编辑批次。历史存于项目规划文件，不发给智能体；AI修改先保存独立提案，用户采用前不覆盖章节。替换已有路线须明确确认，保留新导入的原始源与可撤销的前稿。

“生成路线”打开独立过程窗口，先按需检查回答，再展示总纲与章节细化。用户可见的流式回复、各次纠正及已校验的总纲/章节正文按任务和片段保留，后续批次不能替换前段；不复用题目对话窗口，不显示内置提示词、原始协议或推理原文。支持滚动回看，用户上翻时不强制滚回底部。失败、停止或复核时保留本次已接收内容；成功完整提交后自动关闭过程窗口并进入编辑路线。

生成进度自动保存为独立的`generationDraft`，不修改`routeDraft`。总纲校验后保存，之后每批最多3课通过完整字段和引用校验才落盘；不保存半截JSON、纠错候选或推理原文。超时、停止、退出后从最后保存批次继续，中断批次重新请求，已完成批次跳过。“继续生成”使用当前模型设置；“重新生成”须确认放弃未完成草稿。背景epoch、事实哈希、语言、提示词版本或原路线哈希不匹配时只能重新生成。每次显式继续获得新的请求预算，不后台无限续跑。所有章节齐备并通过完整依赖校验后，原子替换旧路线、清除生成草稿并进入编辑页；校验或保存失败保留原路线及已保存进度。总纲未完成时尚无可续生的结构化进度。

编辑页AI区支持普通问答与路线修改，由AI按完整上下文区分。说明、概述、比较或澄清返回`reply`及`route:null`，兼容省略`route`；不要求重写完整路线，未完成草稿也可讨论。问答不改章节、确认状态、已有提案或撤销记录。明确修改才返回完整v2路线提案，仍须用户采用；仅修订号变化不产生空提案。讨论区分当前路线与待采用提案。大小章菜单均可“添加到对话”，在输入框光标处插入`@第3章`或`@3.1节`，可混合引用最多32个大小章节，同一目标不重复插入。引用以`chapterId/nodeId`绑定，随用户消息持久化；重排或切换语言更新输入中的编号，改名不改变定位。章节顺序以`chapters/nodes`数组为准，编号由当前下标派生，不从ID、标题或旧编号推算；移动保持章节、目标与前置引用的稳定ID，跨大章移动小章后输入与发送引用按nodeId定位新父章。历史消息原文保留，引用展示按当前顺序更新；已删除节点不得改指同位置的新节点。删除输入中的引用文字即取消附带该内容。发送前复核当前草稿，已删除或失效的引用要求重新选择；历史消息保留原ID，不重新指向同位置的其他章节。运行时按ID读取完整大章或小章内容后附给智能体，不接受前端提供的章节正文；完整路线仍作为编辑上下文。相同正文但不同引用视为不同请求；重试沿用原引用，兼容旧单目标消息。网络失败或取消保留原消息，手动重试相同的未回复消息不重复追加；活动请求和修订保护保持有效。

请求绑定项目、ID和基础修订。活动请求不得并发覆盖；取消、失败与重启中断保留回答和旧路线，晚到结果不能提交。重启恢复不重放请求，正常页面读取不取消本进程活动任务。每条消息、历史总量、JSON大小和层级均有上限，超限不创建无法完成的任务。真实CLI接入范围与验证状态按[Agent接入](agents.md)，协议夹具验收不等于完整五项真实访谈验收。

## 规划与校准

先由成果及证据反推能力与先修，再组织阶段和具体活动。学习活动与目标对齐，按基础和材料安排示例、指导练习、独立尝试、解释、操作、反馈修正、跨时段复现及整合应用；交错针对相关辨别任务，不随机打乱先修。正式小章验收仍可省略，无验收仅记录自评或未验证。

估时包含理解、练习、修正、复现、整合和必要准备，外部等待单列。估计有依据与不确定项；目标、期限、预算或资源冲突由用户决定调整，不压缩时长或偷删必需能力制造可行性。首轮代表性任务后按实际耗时、错误、帮助需求及延迟表现校准，不承诺统一课时、复习序列、练习比例或通过率。

AI生成结果和修改均为可审阅提案，关联背景与路线基础修订，采用后提交且可撤销。AI辅助完成不等于独立掌握；评价记录使用的资料、工具及帮助条件，不凭流畅回答或模型总分推断能力。依据与适用边界见[学习计划调研](../research/learning-plan/2026-10-29.md)；本产品效果、估时及AI评价仍需实测。

## 掌握与进度

| 记录 | 含义 |
| --- | --- |
| `locked / available / in_progress / completed` | 节点活动状态 |
| `unassessed / self_reported / demonstrated` | 掌握证据类型 |
| `dueAt / lastReviewedAt` | 独立复习状态 |

未完成的前置节点使节点锁定；用户明确跳过前置时记录原因，不能伪造前置已完成。用户可以自评完成，界面明确显示“自评”，不冒充测试通过。

证据记录 `evidenceId / nodeId / routeRevision / objectiveIds / kind / artifactRef / evaluator / result / createdAt`。AI 评价标记来源并允许复核；缺少标准或资料时不自动判定掌握。

当前进度 = 当前路线已完成小节点数 / 当前路线总小节点数；大章节按子节点聚合。不用游戏等级、浏览时长或 AI 回复数量作为掌握程度。导入空路线不进入学习状态。

路线更新保留历史版本、作品与证据；删除节点从新版本分母移除，历史不丢失；未能对应的记录进入历史区。复习失败不撤回已发钱币，可改变复习计划和掌握提示。

## 背包与工作台

- 资源类型为文件、文件夹、视频、网页链接。节点关联资源 ID；一个资源可被多个节点复用。
- 导入时明确“复制到学习库”或“引用原文件”。文件夹是有边界的导入任务，逐项显示进度和失败；不自动跟踪符号链接。
- 保存来源、哈希/版本、MIME、大小和导入时间。网页保留 URL 与采集时间；视频引用时间段；文档引用页码或段落。
- 不支持的格式保留为附件并解释限制；扫描件需 OCR，视频需字幕/转写，相关能力缺失时不能声称已阅读。
- 资料缺失允许重新定位；更新资料生成新版本，旧引用标记来源变化。删除派生索引不删除原件。
- 问题、笔记、回答、引用和作品绑定项目与节点。笔记是用户内容，AI 改写保留可恢复版本。
- 资料问答明确区分“资料支持”“外部补充”“尚无依据”。引用必须能回到真实来源，超出上下文范围不能假装全文已读。
- 博客、PPT、网页等生成先检测宿主能力；落入学习库的作品目录并记录来源，不自动发布、上传或运行生成代码。
- 导入内容与模型输出均为数据。预览 HTML 使用隔离容器，禁用脚本/任意网络；不执行宏、安装包或文中命令。
- 网络抓取限制大小、超时、重定向与目标地址；禁止借链接访问本机、内网和云元数据。需要认证的内容由用户提供合法副本。

## 复习与学习依据

优先使用主动回忆、带反馈的练习、分散复习、自我解释和工作任务应用。阅读与笔记帮助组织材料，不能替代练习。

产品采用可调整的初始复习间隔，并根据回忆表现、错误类型、时间预算调整；固定间隔只是初始策略，不宣称适用于每个人的最优算法。用户可暂停、改期和关闭提醒，不以断签惩罚进度。

依据：[Dunlosky 等，2013](https://www.psychologicalscience.org/journals/pspi/1529100612453266/) 对练习测试和分散练习给出较高实用性评价；[IES 学习组织指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) 支持间隔学习、测验和深度问题。以上支持方法选择，不保证特定职业技能或个人学习效果。

## 路线分享

分享包仅含路线结构与公开学习描述。导出采用字段白名单，排除个人背景、进度、笔记、资料、路径、账号、Agent 会话及凭据。发布前展示实际包并由用户发起发布；含私人信息的自然语言需单独检查，Schema 无法识别所有敏感内容。

v1/v2路线文件是UTF-8 JSON，不接受压缩包、脚本和嵌入文件；校验大小、版本、字段、ID、目标关联和依赖DAG。未知版本停止导入，既有项目保持不变。来源不可信不妨碍阅读，但不获得执行权限。

项目列表打开按已保存步骤继续；明确点击创建路线且开启AI辅助时回到信息采集，保留旧章节直到生成新草稿，关闭AI则直接编辑。已导入路线在路线入口与编辑页提供删除确认，清除项目导入副本及其编辑草稿、提案和撤销缓存，原文件保留；独立生成的新路线不受旧导入副本删除影响。删除当前导入路线后重新打开项目回到路线来源选择，跨文件中断由读取时按导入记录清理恢复，不能重新带回已删除的路线。

路线来源石牌只选择，不立即保存或跳转。已有章节且改选创建/导入时，“下一步”先确认“已生成的路线会被覆盖，是否确定？”；取消保留保存的选择和路线，确认后再保存来源。改选导入须选择文件；改选手动创建从空稿开始，旧路线进入撤销历史。

可选资料作为规划级资源说明保存并传入规划上下文，不混入某题对话，不重置已采用回答；修改资源且已有路线时仍需确认重新生成覆盖。
