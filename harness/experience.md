# 界面与游戏化

## 视觉方向

2.5D 低多边形魔法冒险：暖色金丝熊、石质控件、柔和光照与清晰前后层次。角色与场景使用协调的切面密度、透视、光照、色温和接地阴影，避免细碎写实背景叠加孤立角色贴图。主页采用简洁的棕褐火山岩与橙黄岩浆场景，金丝熊骑士对抗更凶恶的紫色恶龙。举盾侧的肩、肘、护腕与握柄小爪连接清楚，盾牌不得悬空。标题为 Vibe Improve，保留初始参考图的立体字造型，主页展示尺寸较首版火山主页审阅图放大约 15%，等比缩放，从左上向画面内侧收进并逆时针轻斜约 5°，不遮挡角色头部与操作区。附件只作为风格参考，素材仍须审阅后入库。

金丝熊是学习者化身；大章节是区域，小章节是可选择节点，怪物表达待完成挑战。背景装饰不得遮挡节点、按钮、文字或焦点。

## 界面规则

- 界面只显示功能标题、字段、操作、必要约束、状态与错误。不写欢迎语、宣传语或装饰性解释文案。
- 详情页左上角只保留“返回主页”，不重复 Vibe Improve 标题。
- 所有按钮的底板、图标、真实文字独立维护；按钮素材不烘焙文字。双语切换不更换带字按钮图片。
- 同语义按钮共用组件与状态规则。操作与设置分类使用 `GameButton` 的无字石质底板，主操作、次操作、危险操作共享轮廓；所有整页的返回入口复用 `BackHomeButton`。所在页面或弹窗不得隐式改变同类按钮造型。文字操作、图标操作、账户胶囊和开关保留各自语义形态。
- 全部布尔开关复用 `GameToggle`：圆角胶囊轨道与白色圆形滑块，开启为绿色且滑块在右，关闭为灰色且滑块在左；禁用无悬停或按下反馈。可见轨道随宿主字号缩放，高度保持28–36px，并与承载面板留出上下空间；点击热区独立保持至少44px，不以放大可见开关满足点击尺寸。AI辅助开关的无字石质底板、单行文字与开关分离。
- 操作按钮 hover 使用同色系更深底色，底板亮度为 .78，不旋转色相；原深色文字变白，原浅色文字变黑，整体放大至 1.025，指针为 pointer。按下缩放至 .985，松开恢复；状态过渡为 160ms ease。图标随文字切换对比色，文字不套用底板滤镜。聚焦以底板明暗和文字对比标识，不增加按钮外框；禁用时无 hover/按下反馈。减少动态偏好下取消缩放和位移，保留颜色反馈。
- 浅色面板、窄木质外框与金属包角的组合仅用于模态弹窗。设置、我的账户、项目创建和项目列表等非模态页面不得沿用该围框；展示面使用与场景协调的独立材质，角色、标题、字段和操作不烘焙进展示面素材。
- 设置采用森林营地背景，左侧一级分类，右侧对应设置。分类包括通用、声音、智能体、账户；语言为可扩展下拉菜单，账户提供独立“我的账户”按钮。智能体分类与创建项目共用检测和连接界面，允许随时补充或切换工具。设置不提供按钮悬停预览入口，既有按钮交互保留。日志属于内部运行诊断，不进入设置或其他用户界面。
- 设置外框、标题、返回入口与当前分类标题固定；条目增加时仅右侧内容独立滚动，左侧一级入口始终为限高的纵向列表，分类增加时可独立上下滚动，不横排、不撑高外框；设置标题不进入列表滚动区。左右区域在首尾停止滚动，不带动另一栏或整页；焦点控件在所属区域完整滚入视野。少量内容不强制显示滚动条，选择分类不重置左栏位置，切换分类保留各自右侧滚动位置；下拉浮层不被内容区裁切，接近底部向上展开。长文本增加行高，空间不足时控件移至标签下方，不缩字号或挤出面板。分类、分组和设置条目以稳定ID注册，文案、控件和持久化键分离；增加设置不覆盖旧偏好。实现验收覆盖20项设置、8个分类、12项语言、英文扩展40%及200%文本缩放。
- 主页未登录入口直接叠加认证弹窗；登录、注册、邮箱验证、找回、重置、改密及确认提示共用浅色切面石板、窄木质外框、金属包角面板。采用 2026-10-20 用户认可的 D01–D09 设计。输入纵向排列；关闭图标独立叠加在右上角金属包角，悬停、键盘聚焦与按下时仅叉号变白，背景透明、位置及大小不变；不套用通用图标按钮的方形底色。表单不绘制四周装饰细线。
- 我的账户为独立页面，包含金丝熊角色、用户信息、激活状态、有效期与设备管理；主页账户入口和设置账户入口指向同一页面。
- 已登录未激活时，主页账户胶囊仅显示单行“未激活 / Not activated”；点击进入我的账户页面。
- 注册与密码修改的输入规则、错误和解绑确认属于操作必需信息；不用装饰性文案替代。
- 输入框聚焦与输入时仅内部底色或纹理略微加深，不显示黄色外圈，不改变控件尺寸；复合字段包含密码眼睛与目录图标。错误边框独立保留。密码显示/隐藏只用睁眼/闭眼图标，保留中英文可访问名称、title与按下状态。
- 项目目录在输入框最右端仅放独立文件夹图标按钮，不放带文字的目录选择按钮，不另占一行；保留可访问名称与 title。字段错误反馈使用固定占位，出现、修正或清除错误不挤动后续字段、底部操作或触发跳滚；占位按双语长文本与200%文本缩放验收，不以覆盖或裁切提示保持布局。
- 弹窗按钮点击、按下与聚焦均不增加外框；键盘焦点用底色明暗和文字对比标识。弹窗不显示滚动条，内容按需增高；小窗口或长表单仍可用滚轮、触控板和键盘滚动，不能裁掉字段或底部操作。
- 项目准备页为开阔营地与背包金丝熊的出发准备场景，使用非木框黑板展示面，仅包含名称、目录及保存草稿。字段、提示和按钮保持真实双语文字，不烘焙在黑板素材中。
- 名称与目录之后的智能体选择页采用黑板连接台：左列首项“无智能体，手动创建 / No agent, create manually”，其后列六款工具的独立真实图标、名称与短状态；右侧显示所选项和项目摘要。标题与底部固定、列表独立滚动。保留重新检测；项目模式底部仅“下一步 / Next”，不提供返回名称目录页的按钮，不重复放手动操作。检测中、零可用与失败时手动项可选，选中后下一步可用；尚未选中或所选工具未就绪时禁用下一步，不自动切换工具。设置复用列表，以“返回设置”和“保存”完成默认选择，无项目时隐藏项目摘要。品牌原件、场景、按钮和真实文字分别维护。
- 已安装但可靠探测确认未登录的智能体显示独立“登录 / Sign in”按钮；调用官方登录流程，显示登录中与取消，完成后复查状态。已登录不等于已建立对话；当前准备步骤保存工具选择，后续任务才建立会话。未安装和未验证工具不能选中，不显示无效登录按钮；创建页与设置一致。
- 项目重开先恢复已有规划的访谈或章节编辑；未开始规划时按准备状态进入智能体选择、路线来源或导入预览。目录确认后锁定，后续“上一步”只在智能体、路线来源和规划之间返回；项目模式智能体页不再回退至目录页。目录失效保留记录，先恢复原目录再重试，不替换为其他目录。恢复由已保存业务数据决定，不以最后访问URL或AI回复判断完成。
- 项目列表标题为“项目列表 / Project list”。空旷草原背景上放居中的白色半透明遮罩，不放角色、缩略图或木框。每项显示项目名称、学习进度、最近打开日期、“打开”和“删除”；名称也可点击进入项目，删除沿用公共危险操作形态。不增加搜索框或排序下拉。进度列向名称列靠拢，与最近打开列保持明确间距。无真实路线的项目显示“待规划”，不捏造完成数、进度或日期；审阅样例与真实项目数据区分。
- 列表项目名称最多显示15个Unicode字素簇，超出追加省略号；不拆开组合字符或emoji。悬停显示完整名称，并保留完整可访问名称；仅限制展示，不截断存储值或修改项目名称校验。
- 项目较多时分页浏览，表头和底部分页栏固定，中间项目区域独立上下滚动。分页栏显示当前页/总页、“上一页”“下一页”和每页条数5、10、20；首页禁用上一页，末页禁用下一页，无项目时显示空状态并禁用翻页。切页或修改每页条数后校正到有效页，中间区域从顶部浏览。删除当前页最后一项后回退至有效页；全部移除后进入空状态。操作不挤出遮罩，分页栏不被项目滚动带走。
- 项目“删除”先弹出确认框，确认后仅从本地项目列表移除记录并持久化，保留项目文件和学习资料；取消不改变列表，失败保留原记录并提示。模态确认沿用统一弹窗，不能用临时隐藏一行代替索引提交。

## 准备流程角色

展示角色的步骤使用与主题一致的独立姿态，保持同一金丝熊、红围巾、背包与大片低多边形风格；出发准备阶段不穿盔甲。动作不遮住字段和控件，切换语言不改变角色。信息采集使用小型陪伴角色，路线编辑不单独放置角色。静态姿态即可，素材缺失不能阻止操作。新增姿态按素材流程审阅。

角色外貌以已确认的简化03号`hamster-traveler-v1.png`为基准：圆鼓脸颊、五官比例、配色与少量大切面固定。换动作不重设计面部，不增加细碎三角切面或擅自改变表情；面部切面密度低于身体。

| 步骤 | 动作主题 |
| --- | --- |
| 名称与目录 | 整理背包、安置旅程 |
| 智能体 | 手持通信水晶、举爪介绍伙伴 |
| 路线来源 | 草原岔路，抬爪遮阳眺望，另一爪空手，不拿指南针 |
| 目标与背景、AI规划 | 近满版棕色双轴卷轴，窄边森林背景；对话中使用金丝熊头像 |
| 导入路线 | 展开已有卷轴 |
| 审阅与编辑 | 满版编辑工作区，不放独立角色 |
| 采用路线 | 系紧背包、迈步出发 |

路线来源页采用草原岔路：平坦开阔草原、两块石质路线标志物与两石之间的小河；背景保持简单，不放群山、树林或帐篷。背景、两块无字石碑与真实文字独立，石碑可点击并沿用统一悬停与按下反馈。石碑标题保持单行，按石面空白区域居中并留足边缘安全距离，不覆盖装饰图案、苔藓或边石；使用独立的石碑字号尺度。提供创建路线、导入路线及AI辅助开关；无智能体时AI辅助关闭且禁用，手动流程仍可继续。

导入路线弹窗并列在线路线和本地路线。在线路线显示“暂未开放”，整体置灰且禁用，不触发请求、聚焦或hover。启用的本地路线提供“选择文件”，取消文件选择后保留弹窗；校验成功进入预览，展示大/小章节、目标与可选验收标准。用户确认“保存路线草稿”后持久化，不覆盖已采用路线或学习进度。关闭或取消返回路线来源页并保留选择与既有草稿。

信息采集采用近满版棕色双轴卷轴，四周露出窄边森林背景，与编辑页保持同一材质和画风。卷轴保留大切面纸纹、自然卷边和棕铜色边轴，中央保持清晰；背景、无字卷轴、控件与文字独立。卷轴按九宫格适配窗口，端帽不拉长，装饰不接收交互。保留现有组件：左半上方固定模型、推理强度和当前采集问题，下方为智能体与用户的对话，底部固定消息输入；右半显示五项采集清单、完成状态、回答摘要及原回答依据。智能体头像复用当前provider的真实图标，用户头像为已确认金丝熊；不额外占用大幅角色栏。对话填满剩余高度，与清单独立滚动，问题、输入和主操作保持可达。返回主页与上一步使用与编辑页相同的定位层，切页时位置、尺寸一致；窄屏改为纵向布局。回答充分后先展示总结，用户采用后才进入下一问题，必要项全部采用后启用“生成路线 / Generate route”；可选资料不阻塞。用户可修改已完成项、停止请求或转手动；AI拟定的目标、标准或关键假设须有用户明确采用，状态规则按学习领域实施。重开恢复已保存状态，失败保留回答并显示必要错误，不伪造完成或生成结果。

路线编辑采用目录式工作台：满版棕色魔法卷轴，无边缘宝石，不放独立金丝熊。左侧统一大章与小章目录，中间仅编辑选中的大章或小章，右侧保留AI对话；三栏独立滚动，标题、路线名、保存状态和底部主操作固定。大章与小章不再分成两套导航。默认只展开当前大章，小章显示名称、目标及预计时长；验收标准和更多设置默认折叠。大章名称可进入阶段目标编辑，增删、排序及路线来源操作通过对应入口保留；长标题省略并可悬停查看全名。菜单支持键盘和取消，不被滚动区域裁切。AI启用时对话及输入直接可见，无AI时隐藏该区并扩展编辑空间；修改提案在对话中通过“查看修改”展开，用户采用或放弃，未采用不改章节。AI生成、手动和导入共用编辑器，导入不强制访谈。人工保存和采用提案可单步撤销；未完成草稿可保存，确认须通过完整路线校验，当前仅保存路线修订。

编辑页对话既可询问章节，也可提出修改，不要求命令格式。等待时显示处理中与停止，失败在对话区提示并提供重试，保留输入；失败重开后保留的未回复消息仍可重试，不自动重发。用户停止后恢复输入，不清除尚未发送成功的文字。普通问答只追加回复，不生成空修改提案；实际分支按[学习领域](learning.md)实施。

宽屏工作台使用可调整的资料/阅读/助手区域，窄屏切换标签保留状态。地图提供等价列表视图，支持平移、缩放、键盘选择与“回到当前节点”；缩放后标签与点击区域仍可用。

初始内容区按视频1920 × 1080、16:9建立，工作区不足时等比缩小，不留黑边；支持用户主动进入全屏。主页使用1672 × 940.5逻辑画布，背景、标题、右侧纵向按钮和账号整体等比缩放，空余区域补纯黑边。窗口初始化、比例与全屏行为统一见[窗口与全屏](window-layout.md)。

主页菜单文案为“开始新项目 / New Quest”“加载项目 / Load Quest”。账号使用白色胶囊框包住深色图标与“我的账户 / My account”，不使用石质按钮外观。

## 字体与双语

- UI 所有按钮、正文、输入、节点、提示与状态使用真实文本及可商用、可分发的黑体；当前中英文采用思源黑体 Source Han Sans CN。仅固定标题允许图中文字，并提供可访问名称及中英文对应资产。
- 字体用本地 `@font-face` 加载，实际文件与对应许可放正式资产目录，具体发行文件按 [assets](assets.md) 核验。不要依赖运行时外部字体 CDN。
- 按钮文字本身按按钮几何中心水平、垂直居中，图标独立置于左侧；文本区两侧保留对称空间，避免文字与图标冲突。图标与文字不作为整体居中。按钮与其他可点击控件的中英文功能文案保持单行；按完整译文扩展宽度，空间不足时重排整组控件，不在控件内部折行。
- 当前支持 `zh-CN / en`，文案统一管理，不拼接语序、不把翻译写入图片；切换语言不改变路线、证据或数据 ID。新增语言须先通过同一布局验收。
- 翻译后的按钮、标题、正文、字段、提示及状态完整保留在各自容器内。功能按钮和可点击标签保持单行，使用自适应宽度与整组重排；标题、正文、说明和用户内容可按需换行。窄屏容器允许滚动，不能遮住末尾操作。以英文扩展 40% 和长中文做压力检查，不以隐藏 overflow、裁切、单行省略或缩小字号处理翻译。
- 弹窗按钮使用无字独立底板；文字与底板不固化、不共同滤镜处理。文本两侧及上下预留安全区，按完整单行文案确定宽度；确认按钮在窄屏改为纵向，验证码重发按钮可以整块移至下一行。文字必须完整保留在按钮可见边界内。
- 用户昵称、邮箱的紧凑胶囊及项目列表名称允许省略，并提供完整值的 title；项目名称按上述15字素簇规则展示，路线草稿的紧凑标题入口也允许省略并提供完整title；其他功能文案不省略。使用逻辑方向样式，长连续字符串可在容器内折行。
- 字体覆盖缺失时逐字回退系统字体并记录问题；拉丁文、标点、数学符号、代码与生僻字都要检查。不能声称一个中文字体覆盖全部资料字符。
- 课程保持作者的内容语言；翻译是显式操作，保留原文、语言和路线版本。

## 动效与奖励

- H1 首页使用已采用的 1080P、24 fps、约 8.04 秒火山视频，素材见 [assets](assets.md)。金丝熊左手举盾挡火、右手持剑，紫色恶龙朝盾牌喷火；岩浆流动、火山烟雾上升与扩散，当前环境动效速度约为初版的 2 倍。标题、按钮与账号区域沿用已确认布局。
- 首页背景视频不含标题、按钮、图标或文字；Vibe Improve 标题与右侧按钮底板、图标分别作为独立素材叠加。按钮文案使用真实双语文本，交互由 UI 控件承担。视频提供对应静态 poster，播放不依赖实时 3D。
- 首页提供暂停/播放，尊重减少动态效果与简化视觉；离开首页或切后台暂停，用户暂停后不擅自恢复。加载或解码失败使用静态画面，主要操作不等待动画。
- 默认 2.5D；3D 模型与骨骼动作保留用于 Skill 内部有价值的局部互动，不能成为完成学习的前置依赖。
- 完成事务提交后播放击败怪物动画。跳过、减少动态效果、切后台、刷新、资源丢失或 WebGL 失败不影响进度。
- H3 启用奖励后，每个学习实例的节点首次完成产生一次奖励，唯一键为 `projectId + stableNodeId + first_completion`；路线小修、重放事件和动画不能重复发币。
- 钱币为不可兑换现金的学习激励，不由 AI 文本改余额。未来商店通过独立交易账本扣款并解锁皮肤，外观不改变学习结果。
- 复习采用独立有上限的奖励策略（实现时定义），不允许通过重复提交同一事件刷币；现在不实现商店。

## 可用性验收

最低检查桌面 1280×800、1440×900、1920×1080，以及移动复习 360×800、390×844；200% 文本缩放不遮挡主要操作。正文不低于 16 CSS px，常用点击目标至少 44×44 CSS px，状态不能只靠颜色或动画。

所有地图动作有真实控件、可见焦点、键盘操作和可读名称。动画可跳过并尊重减少动态效果设置；低配模式使用静态图/精灵。加载、空内容、离线、资源缺失和长列表都有可操作的状态。视觉验收用截图和交互证据，不仅看组件渲染成功。

主页循环至少连续观看十轮，检查角色一致性、举盾、受力、火焰遮挡和接缝；标题与按钮叠加后检查遮挡与双语布局，实测编码体积、持续播放与切页停止。首尾同图输入不代替循环验收。播放约束见[播放调研](../research/home-loop-animation/2026-10-14.md)。内部 3D 互动另检查模型变形与刚性装备，参考[3D 制作调研](../research/rigged-3d-characters/2026-10-14.md)。

新设备绑定使用现有独立按钮与石纹确认弹窗，显示“绑定当前设备”、已用/总名额、“暂不绑定”和“确认绑定”；中英文功能文字保持单行且不得超出按钮。网络后台恢复三次仍失败时切到登录弹窗，不展示内部日志或令牌。

项目列表打开按已保存步骤继续；明确点击创建路线且开启AI辅助时回到信息采集，保留旧章节直到生成新草稿，关闭AI则直接编辑。已导入路线在路线入口与编辑页提供删除确认，清除项目导入副本及其编辑草稿、提案和撤销缓存，原文件保留；独立生成的新路线不受旧导入副本删除影响。删除当前导入路线后重新打开项目回到路线来源选择，跨文件中断由读取时按导入记录清理恢复，不能重新带回已删除的路线。

采集页五项状态在桌面窗口内同时可见，不随对话自动滚走；已完成项显示勾选与“已采集”，状态、计数及当前问题从同一份领域数据更新。当前问题提供简短引导与示例，允许“不知道”并继续澄清；示例不作为用户答案。可选资料在弹窗中补充，不挤占清单。用户头像使用已确认金丝熊，面向左侧对话，完整显示耳朵和脸，不更改角色原素材。

路线编辑使用暖棕卷轴独立图层，置于冷色森林背景。大章使用透明底色、独立编号与粗体，小章缩进并使用分支线和较小字号；选中态与章节层级分别表达。大小章标题悬停不变底色，仅大章标题文字轻微放大；添加大小章悬停只加下划线，不加底色或缩放。编辑区提供直接删除入口，目录菜单保留排序和删除，弹窗确认后清理相关前置引用。采集页与编辑页共用导航组件，返回主页和上一步始终在左上方同一行，采用相同的石质按钮；AI创建返回采集，手动或导入返回来源选择，均不退回项目目录。保存草稿始终允许主动提交，已保存且无改动时保持路线修订和确认状态；确认路线先显示具体待补项，可定位到所属章节，完整后才提交确认。

所有可见滚动条共用`scrollbars.css`的橄榄绿滑块、金棕边缘与浅色轨道，支持拖动、悬停与系统高对比模式；弹窗内仍隐藏滚动条并保留滚轮和键盘滚动。规划路线和编辑路线的AI对话头部均提供模型与推理强度，按当前CLI实际返回的能力展示；不支持的强度不可选择。偏好只作用于当前项目及后续请求，不修改全局智能体配置。

路线编辑器的三点、折叠箭头、撤销与前进图标悬停/键盘聚焦时只加粗描边，背景透明、不缩放；不可用图标不加粗。小章“验收标准”和“更多设置”标题使用浅棕透明悬停色，覆盖整行边框内部，正文区域独立。章节引用直接显示在聊天输入框内，中文为`@第3章`、`@3.1节`，英文为`@Chapter3`、`@Lesson3.1`；支持多个引用与普通文字混排，插入后聚焦输入框，不另设外部引用标签。输入框与已发送消息中的引用均使用无边框、浅绿色填充标签；输入换行、滚动及选中文字时标签与文字保持对齐。引用视为整体：退格或向前删除触及标签时删除完整引用，插入后紧邻的一个尾随空格随退格一并删除；部分选中标签后删除也删除完整标签。普通文字维持原生编辑与撤销行为，输入法组字期间不拦截删除。按钮文字保持单行。

采集页的编辑入口无底色和缩放，悬停仅加下划线；无已有路线时显示“手动编辑路线”，已有路线时显示“编辑已有路线”。每题独立展示问答、回答总结、“确认回答”和“重新回答”，采集状态区分待补充、待确认与已采集。目录不设置独立的添加按钮：大章三点菜单仅提供“添加大章节”，小章三点菜单仅提供“添加小章节”；空路线从路线三点菜单添加首个大章，空大章的小章占位行提供添加首节的三点菜单。新大章插在所在大章后，新小章插在所在小章后。上移、下移、移动到统一置于“移动”二级菜单。移动到弹窗完整展开可滚动的章节索引树，大章只可选另一大章之后，小章可选大章首位或另一小章之后；自身、当前位置与满额目标不可选。移动后目录、详情与引用编号统一按当前顺序计算，目录定位到被移动项；中英文菜单保持单行，支持键盘与取消。

规划和编辑的对话区显示 CLI 实时活动面板：当前阶段、耗时、思考/输出字符累计、最近活动时间及可展开阶段记录。30秒无有效新活动显示等待提示，不判定为断网；停止或失败保留本次面板，成功由正式结果替换。规划和编辑的AI对话在新消息、流式增量、总结/活动区域增高及窗口尺寸变化时始终滚到容器底部，不因用户曾上滚而停止跟随；只滚动对话容器，不移动整页。复核卡可保持顶部阅读，独立生成窗口仍支持上翻回看。活动详情独立滚动，双语适配。

AI对话输入支持输入法组字与英文原文确认。输入法确认的回车不发送、不干扰组字；兼容组合状态、229键码及WebKit先结束组合再送回车的顺序，确认键释放后的下一次普通Enter才发送。Shift+Enter仍换行，点击发送仍可用；组合期间不劫持章节引用删除，长按回车与同次重复触发不重复提交。

生成窗口的停止按钮使用独立图标与文字标签，图标不混入文字行内；图文整体水平、垂直居中，保持单行。底部操作区预留悬停放大的空间，中英文按钮及标题、状态、计数在小窗口和全屏均不得被裁切或越出容器。
