- 日期：2026-10-27
- 状态：安装、认证探测、两轮真实对话通过；学习任务适配器仍为 probed。
- 范围：macOS、Node.js 22.22.2、@tencent-ai/codebuddy-code 2.177.0、国内站。

## 实现

界面使用 CodeBuddy 替代 WorkBuddy，移除 TRAE，检测总数为六款；保留手动创建。采用官网原版 CodeBuddy 图标。未安装或发现未核验版本时显示安装按钮；需认证时显示登录按钮。中英文按钮使用既有独立素材与真实文字组件。

安装使用应用内固定脚本、完整依赖锁文件和官方发行文件 SHA-256 指纹。npm ci 固定官方源、关闭生命周期脚本，不全局安装；下载先进入隔离目录，校验后切换至托管目录，失败保留原安装。取消终止本次 npm 操作并清理隔离目录。没有 Node.js 18.20.8 以上版本或 npm 时明确提示，不伪装安装成功。

配置、缓存与托管CLI位于`Vibe Improve Runtime/agents/codebuddy/`；程序更新保留运行目录。凭据由官方CLI管理，不复制 WorkBuddy 令牌，也不把旧WorkBuddy/TRAE选择记录自动转换成CodeBuddy身份。旧选择保留，当前界面返回未选择。

SDK initialize 只探测认证，不发送模型请求；前端不接收账号、token或原始协议。官方交互式登录由受控终端承载，账号确认由官方浏览器完成；完成后另起进程检查认证保持。国内站在进程启动前固定环境，与检测、登录及对话一致。
