# 窗口、全屏与尺寸

## 初始尺寸

所有尺寸为逻辑像素：网页使用 CSS px，原生壳换算为对应平台的逻辑单位，不乘显示器像素密度。窗口大小描述内容区，原生标题栏与边框另计。

| 项目 | 规则 |
| --- | --- |
| 初始内容尺寸 | 视频原尺寸1920 × 1080，16:9 |
| 独立窗口首次打开 | 居中；`s = min(1, 可用工作区宽/1920, (可用工作区高−原生标题栏高度)/1080)`，内容区为 `1920s × 1080s`，初始无黑边，不裁切或拉伸视频 |
| 独立窗口建议最小尺寸 | 1024 × 576；工作区不足时以实际可用空间优先 |
| 再次打开 | 当前居中打开普通窗口；后续增加窗口位置恢复时校正到当前工作区，不保存全屏尺寸覆盖普通窗口尺寸 |
| 初始状态 | 普通窗口；用户主动进入全屏，不因启动、切页或恢复状态自动全屏 |

macOS 壳创建原生窗口，通过系统入口或 Control–Command–F 切换全屏。网页版由浏览器决定窗口尺寸，不强制修改浏览器窗口。原生与浏览器全屏分别验收。

## 主页适配

- 主页为 1672 × 940.5 固定画布。背景、标题、四个菜单按钮、图标、真实文字与账号区域共享同一缩放，元素间比例与相对位置不变；业务元素仍独立维护，不烘焙进背景视频。
- 初始窗口按上述视频比例建立；用户后续缩放窗口或进入全屏不锁定宽高比，继续沿用以下适配方式。
- 视口为 `W × H` 时，缩放 `s = min(W/1672, H/940.5)`；画布宽高为 `1672s × 940.5s`，水平、垂直居中。空余区域使用纯黑 `#000000`，不拉伸、不裁切或模糊延展。16:10 视口左右贴边、上下补黑；比画布更宽的视口左右补黑，以保留完整画面。
- 标题在基准画布 `(85,12)`，宽 640、保留纵横比与 -5° 倾斜。四个菜单按钮在画布右侧纵列：起点 `(1309,224)`、宽 346、高 101.032、间距 24；文字 26.2，按按钮本身居中。尺寸统一乘 `s`，不单独限制大小、不切换底部布局或重排。
- 文案固定为“开始新项目 / New Quest”“加载项目 / Load Quest”“设置 / Settings”“退出 / Exit”；基准尺寸保持单行，翻译或文本缩放超出时按[双语规则](experience.md)换行增高，不裁切。图标独立位于左侧，文字按按钮几何中心居中。
- “我的账户 / My account”为白底深色图标和文字的胶囊框，基准位置 `(1410,36)`、宽 240、高 64、圆角 32；图标和文字作为一组居中，不使用石质按钮外观。账号功能接入后使用符合实际导航的语义；未接入的审阅版只作展示。
- 主页画布内不显示最大化或全屏按钮；使用浏览器或系统窗口的全屏入口，审阅版工具条位于画布外。
- 桌面建议最小内容区 1024 × 576，在该范围内主菜单文字至少 16、按钮高度至少 44 CSS px。更小面板只作固定画布缩略预览；移动学习与复习使用专用布局，不把桌面主页缩略图当成移动页面验收。
- 像素密度仅影响素材清晰度；不改变逻辑字号和点击面积。当前媒体为 1920 × 1080 视频及同尺寸 poster，以 `contain` 放入 1672 × 940.5 的逻辑画布；媒体与 UI 共享画布缩放，不裁切、不随媒体分辨率改变控件坐标。高密度大屏可另备更高分辨率母版，并按实测性能选择播放版本。

学习工作台全屏使用增加的空间扩展阅读/资料/助手区域，正文仍不低于 16 CSS px；长篇阅读区限制行长，不将正文随屏幕宽度无限放大。断点与双语约定见 [experience](experience.md)。

整页返回入口、按钮类别、展示面材质与字段错误占位统一按 [界面规则](experience.md) 实施；窗口大小变化不切换同类按钮造型，不把非模态展示面改成模态木框。

## 全屏行为

- 审阅版由画布外工具条的按钮触发网页 Fullscreen API，监听 `fullscreenchange` 更新实际状态；Esc 保留浏览器退出行为，不锁键、不拦截系统快捷键。
- 请求失败或环境不支持时保留普通窗口的完整功能，提示可使用浏览器或系统窗口全屏。收到 Promise 成功和实际全屏状态前，不显示“已全屏”。
- 进入/退出全屏、调整窗口或换显示器只重算布局，不重建学习会话、重置表单、重复播放奖励或自动恢复已暂停动画。
- 全屏中使用浏览器或系统退出入口，保留键盘焦点和减少动态效果设置。网页全屏时焦点进入预览区域，退出后回到原有窗口布局及画布外的全屏入口。
- macOS / Windows 系统原生全屏、浏览器窗口最大化和网页元素全屏分别验收，不以网页原型代替原生壳支持证据。

API 依据：[requestFullscreen](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)、[fullscreenchange](https://developer.mozilla.org/en-US/docs/Web/API/Document/fullscreenchange_event)。

## 验收

检查 1280 × 800、1440 × 900、1920 × 1080、2560 × 1440、3440 × 1440、1024 × 576，以及缩略预览；分别检查中英文、浏览器缩放、进入/退出全屏、拒绝/不支持、窗口恢复与屏幕变化。画布始终完整、黑边对称且纯黑，按钮与画布宽度之比固定为 `346/1672`，菜单留在画布右侧，账号为白色胶囊框。正文与工作台的 200% 缩放另按通用可用性规则验收；尺寸变化不丢学习状态。
