# 验证

智能体准备验收覆盖：名称/目录保存后进入选择页、首项手动选项、六款真实图标、逐项安装/认证状态、需登录入口、重新检测、上一步与下一步、设置默认选择、项目独立选择和重启恢复。检测中或失败仍可手动继续；未就绪工具不可选择；保存时再次核对认证；并发检测迟到结果不能覆盖新一轮或用户选择。浏览器无原生桥接时明确提示桌面端要求，不能伪造本机检测。认证进程覆盖完成、取消、超时、代码输入与受限官方URL；凭据与原始输出不入盘、不入日志。适配器真实模型对话另行验收，不以已登录代替。入口为 `tests/agent-selection.test.mjs`；中英文及小窗口检查全部七项、固定页脚、独立滚动与按钮文字边界。


CodeBuddy覆盖官方npm发行文件核验、Node版本、SDK认证探测、加密信封不误判就绪、受控终端官方登录、URL白名单、已有认证不重复登录、登录完成后新进程复查及token不进入返回值。安装覆盖锁定版本、仅官方源、关闭安装脚本、临时目录原子切换、失败保留旧版本、取消与错误脱敏；生产资源不依赖tmp。旧WorkBuddy/TRAE选择不复用身份，不显示TRAE选项。入口为`tests/codebuddy-install.test.mjs`及`tests/agent-selection.test.mjs`；真实安装和模型回复单独记录。

项目准备与列表验收覆盖：系统目录选择/取消、表单恢复、保存待规划草稿、重启后打开与修改、重名/保留名/非法路径/UTF-8长度、命令重试、旧修订冲突、目录缺失后保留记录、恢复原位置重试及拒绝修改已确认目录、损坏或符号链接索引不丢原数据。草稿不提前创建用户项目目录，不伪造路线或进度；项目诊断不含名称、路径和书签。双语检查包括黑板创建页、居中白色半透明列表遮罩、标题“项目列表 / Project list”、列表无角色与缩略图、输入复合焦点及按钮文字不超出底板。名称覆盖15与16个中文/英文字素簇、组合字符和emoji：超出15个追加省略号，悬停及可访问名称保留全名，存储原值不变。进度与最近打开有独立间距，不因长名称挤靠或重叠。每项保留项目名、学习进度、最近打开日期、打开和删除按钮，项目名也可点击；不增加搜索框或排序下拉。无真实路线显示“待规划”，审阅样例不能充作真实进度记录。契约见[项目草稿](../contracts/project-draft.schema.json)，自动化入口为 `tests/project-drafts.test.mjs`。

项目分页与删除验收检查固定表头/分页栏、中间区域独立滚动、当前/总页、上一页/下一页、每页5/10/20条切换、首尾页禁用、空列表以及删除当前页最后一项后的有效页回退；切页和修改每页条数后滚动归顶，长列表和200%文本缩放均不遮住操作。删除覆盖取消无修改、确认后索引原子移除、重启不恢复已移除记录、重复请求幂等、写入失败保留记录和现存项目文件完整不变；界面不能仅隐藏一行便声称完成持久化删除。

界面一致性按[界面规则](experience.md)验收：同语义按钮在主页、设置、账户、项目与弹窗使用同一轮廓和状态，分别检查正常、hover、按下、键盘焦点、禁用及减少动态效果；按钮文字完整位于底板安全范围，图标不挤偏文字。目录末端仅有文件夹图标。有效名称、空名称失焦、非法名称及修正后四种状态中，目录控件位置与尺寸偏差不超过1 CSS px，错误出现不改变表单滚动位置；中英文与200%文本缩放都须通过。木框与金属包角组合仅见于模态弹窗；场景素材和独立面板均做目视检查，新美术未经用户确认不登记为已采用。

## 日志与翻译

- 按[日志规范](observability.md)验证固定字段与枚举，使用合成敏感值证明浏览器、原生、云端及内部读取内容均无身份、凭据、正文、路径、URL 或原始异常信息。
- 验证浏览器条数与字节上限、损坏输入、存储拒绝与内存降级；原生日志验证容量轮换、文件权限与链接防护，内部读取和清理仅面向开发诊断；写入失败不影响业务。用户设置与页面不显示日志分类、导出或清除控件。
- 认证映射覆盖SDK固定错误码、验证码发码/验码的阶段差异、域名、邮件配置、网络、限流和未知错误；通过实际API模块的SDK替身验证日志写入，不能只测映射函数。
- 使用合成账号实测错误密码登录、无效激活码及其云端关联；服务端记录与客户端的 `traceId / serverTraceId / clientTraceId` 须匹配，记录原因及阶段。真实邮件送达单独验收，不为制造故障修改共享认证配置。
- 验证新旧客户端请求兼容、非法 trace 拒绝、前后端 `clientTraceId` 关联；业务失败重试保留 `requestId`，更换诊断 ID，不改变幂等结果。
- 对 `zh-CN / en` 的主页、全部认证弹窗、设置及账户状态逐一验收，再检查英文扩展 40%、长中文、长连续字符串与 200% 文本缩放。按钮与正文换行撑高，窄屏滚动后操作仍可达；检查文字边界及实际交互，不能只看页面无横向滚动。
- 用户昵称、邮箱胶囊及项目列表名称可省略且须提供完整 title；项目名称另验收15字素簇边界及全名可访问性。其他翻译不能依赖隐藏 overflow 或缩小字号通过检查。

## 证据格式

每次验证在 `tmp/checks/<任务>/` 保存：命令/操作、版本与平台、输入、预期、结果、失败与限制。截图记录语言、视口和状态，不能用静态图证明交互或真实集成成功。

使用假时钟测试时间边界；授权测试使用隔离测试密钥与服务，不调用生产账号、支付或自动撤销真实设备。

- 新设备有空位时只显示绑定确认，取消后保留登录且不占位；关闭、手动检查、冷启动不自动绑定。满额不显示可确认绑定；腾出席位后再次询问，确认前容量变化由服务端拒绝超额。已有绑定不重复询问，激活仍为首次绑定原子事务。

- 账户兑换入口覆盖已激活与已到期状态；空码/空格禁止提交，处理中禁止重复提交与关闭。失败保留输入，取消/重开及切换账号清空；成功采用服务器返回的有效期和原设备信息，不在前端累加天数或保留激活码。中英文入口和弹窗文字不得越界。

- 验证授权到期、设备撤销、证书无效及首次登录后的授权校验失败均保留有效账号会话，同时`requireFeature`拒绝；重启不能复活无效授权。覆盖权益剩余不足5分钟时不连续续租、短租约有间隔、7天静默认证与三次网络失败退出仍有效。连续更新三版二进制后，运行目录及身份、成对加密会话、设置、项目、工具选择和日志原样保留。聚焦、输入、失焦及密码/目录复合控件均无黄色外圈，焦点以内层轻微加深表示，错误反馈仍可辨认。

流程回归包括：智能体首次探测、并发进入复用同一检测、跨进程缓存恢复不启动CLI、手动刷新与单工具认证刷新；项目目录锁定及后续无回退目录入口；AI按完整上下文判断采集完成，覆盖归纳改写、数字转换、自然同意、跨轮建议、未知或灵活安排、含糊及矛盾追问、目标变化重评。清单按结构化判断同步更新，不用关键词或逐字匹配判定；格式矛盾、虚构消息、空完成和晚到结果不能提交，旧v1进度可恢复。采集五项在1440与1024桌面窗口内同时可见，中文与英文按钮保持单行；头像面向左侧且耳朵与面部完整。
