# 学习领域

## 访谈与路线

默认采集学习方向、达标表现、已有基础和每周时间。第一题确定领域或待解决的问题，第二题确定学完能独立完成的事与可观察的达标表现。用户可直接描述期望成果，AI 按需建议具体的达标标准，由用户确认。首次显示一句问题、一句作答帮助和一条简短示例，追问只问一个具体问题。已有基础提供贴合主题的快选，包括从未尝试、跟过示例、能独立完成简单任务及不确定，也支持自由回答。清单独立滚动，选中项自动进入可见范围。依据见[学习路线的证据与最小访谈](../research/learning-plan/2026-11-07.md)。

采集采用引导式对话。用户不熟悉领域时，先解释当前选择的含义，再给贴合其用途的例子或至多三个具体方向；仍无法选择时提出一个可调整的入门建议。用户询问术语或区别时先回答，再回到当前问题。长解释留在聊天，顶部只显示短追问；信息足够时直接总结，不重复科普或追问。零基础不能替代目标选择；一个明确建议后的同意可关联采用，多个不同选项后的含糊同意继续澄清。未知基础和时间如实保留，不虚构能力、时长、期限或保证成果。普通补问返回成功的未完成访谈状态，不报任务失败；用户确认总结后才进入下一题。总结、继续补充与回看已确认问题时，均可展开查看实际采集字段与完整值。所有智能体使用同一规则，结构和来源校验不代替模型的语义判断。

每题按规划用途判断信息是否充分；状态区分待采集、当前、待补充、待确认、待复核和完成。智能体只处理当前问题，提取信息并判定充分后生成回答总结；AI整理后明确询问“是否确认该回答？”，用户确认后才标为已采集并进入下一项。新答复或修改均须重新总结和采用；含糊、矛盾或不完整回答留在当前题继续补问。AI自行拟定的目标、标准和关键假设须经用户认可，不能凭空勾选完成；切换清单仅查看，不自动删除内容；可对选中的题点击“重新回答”，确认提示后清空该题及之后全部题目的回答、题内消息、快照、总结、证据和采用事件，从该题依次重新采集。之前的回答保留；取消提示不修改任何数据。统一“重新采集”经确认后清空全部回答、题内消息、待确认总结、已采用快照、采用事件、复核事项与可选资料说明，从提升目标重新开始；保留项目目录、名称、智能体及模型选择。已生成路线和编辑历史保留至新路线完整成功后替换。按需补问合并在对应题内；可选资料不计入完成门槛。必要项全部满足且没有活动判断或冲突时才启用“生成路线”，运行时按结构及版本复核，不以模型文字或前端勾选直接放行。

确认一题后，下一题可从前面已确认题目的用户原话提取本题信息。信息充分时显示待确认总结，部分充分时带入已有信息并只问缺口。用途已明确时带入待确认答案，仅在用途影响路线且仍不清楚时追问。考试或交付等固定期限仅在影响可行性时追问。时间未知时可选择暂不排期，确认后按学习顺序生成，后续按实际投入校准。设备、费用、内容取舍和期限按需询问。

先确定独立表现任务、允许的帮助和可观察证据，再拆成大章节和小节点。每项核心目标与练习和同层次的达标证据对应。实操先安排有指导的小任务，逐步减少提示，最后用新案例检查独立应用。公开题面给条件和核对方法，完整答案留给学习者推导。每个节点有稳定 ID、目标、前置依赖和估计时间。路线阶段不预设 AI 测验、答案、复习内容或复习通过指标；这些应根据学后的提问、笔记和练习表现生成。已确认总时间时在总纲分配课时。依据见[学习路线质量标准](../research/learning-plan/2026-11-12.md)。

实操路线按目标和起点确定一套主方案。采集保留用户明确要求或偏好的语言、框架与工具；未指定时由 AI 推荐。章名和学习目标表达实际知识、可迁移技能及可观察表现，可点名必要的领域技术；自定义字段、文件和样例编号只放入实际用到的练习步骤，说明用途。标题和实际活动必须相符。非软件主题沿用本领域的方法和材料。

总纲用 `practiceRules` 记录须跨章复用的接口、参数、比较基准和起止状态。细化和审阅共用这组约定。依赖前章具体产物的章节用 `prerequisiteChapters` 标记直接依赖，细化等待其完成并优先读取对应公开练习，核对产出方实际可取得的记录与状态。练习要求特定状态时提供可读初始记录或可重复触发条件。仅复用方法的练习可另起案例，明确输入。纸面模拟提供验收所需的原始记录，包括操作后的回报或明细，或给出能推演这些记录的事件及规则。按样例推演流程，复算参考值并核对精度与容差。重复同一未终结请求时核对实际状态和记录条数。各路径按可观察证据分别验收本地写入、渠道回执与对方接收。正文用章节标题指向前置内容，任务短引用留在协议字段。

生成提示词按教程组织知识进阶。大章明确知识领域和阶段能力。AI生成或实质改写的小章提供`activities`，写出练习输入、操作、结果和自查方式。用错误原因、修正及重试提供反馈。需要复习的内容与时机根据实际学习记录确定，不在路线中预设复习任务。目标说明动作、对象、条件和成功表现，阈值须有任务依据。先修不明时安排小范围校准或补习。总纲与细化任务在返回前自查内容，运行时验证结构、范围和引用。AI修改限于用户指定范围。新提示词用于新生成或用户请求的修改。

大章节按能力阶段或任务复杂性组织，不因小章数量、篇幅或估时均匀拆并章节。生成采用路线v2：大章必填`stageGoal`，契约允许小章省略`activities`以兼容手动与导入路线，AI生成遵循上述教学要求；新生成小节不含测验或复习配置；任务协议允许省略 assessment 或返回 null，拒绝在细化阶段填写测验对象或 review。旧路线中的 task／answer／objectiveIds，以及 passCriteria、mode、evaluatorPrompt 和 review 继续读取与恢复。v1仍可导入，保留完整原始路线，升级草稿的大章目标留空，由用户填写或明确采用后才可确认，不静默丢字段。

路线只规划目标、方法、先修、学习活动与估时，不提前出题或配置复习。学后测验与复习应结合实际提问、笔记、练习及目标，区分已理解内容、疑点和缺少证据的部分；没有学习记录时不能假装已做学情分析。题目和答案或评判标准分离，支持多种题型与等价表达，避免用逐字匹配判定开放回答。此部分属于后续学习工作台能力，当前未接入完整的笔记与片段问答，也不在路线页提供提前生成入口。

已有路线和旧生成检查点保留测验、答案及复习字段，继续支持保存、导入、学习页读取与撤销恢复。规划审核和后续细化上下文不带入旧测验内容；新生成批次不新增测验或复习。编辑其他内容时保留旧字段。旧草稿包含不完整的测验或复习配置时，编辑器明确提供移除未完成旧配置的操作，仍可撤销；不静默删除，也不要求填写新的测验。

AI 生成与导入路线使用同一 [路线契约](../contracts/route.schema.json)；运行时共用 [JavaScript校验器](../packages/domain/route-validation.mjs)，离线检查保留 [Python校验器](../scripts/validate_route.py) 并验证一致性。确认通过校验的路线修订后进入冒险地图。打开已确认的项目直接恢复地图。小节详情使用路线中的目标和活动；兼容读取旧路线的测验与复习，支持自评完成。导入不要求再调用AI。

## 已实现的规划流程

访谈、总纲和课批次共用[内置提示词包](../packages/planning-prompts/README.md)的核心规则、教学标准与任务契约，由AI结合当前题本轮对话和已采用答案判断是否足以规划。外层统一返回`status / reply / result / missing`；当前题结果包含`questionId / complete / summary / fields / evidence / unresolved`，运行时转换为既有领域格式。`ok`只表示本次任务有效，不表示用户已采用；`needs_input`与`cannot_complete`不能继续应用路线。识别自然同意、跨轮补充、定性标准、灵活时间和明确无条件；不按关键词、数字写法或逐字匹配判定。含糊、矛盾、未认可的建议继续澄清，关联冲突返回结构化待复核事项，不能静默改写其他已采用项。可选资料不阻塞；未知基础须认可合理起点，时间未知须认可相应安排。

`packages/domain/planning.mjs`管理采集、消息关联、请求修订及编辑草稿，[规划契约](../contracts/planning.schema.json)定义持久化结构。AI 返回待确认总结，运行时校验格式、消息关联和修订。证据可忠实归纳；采用建议须关联当前题真实用户回复和早先建议。四个核心问题均完成、无待复核事项及活动请求，并拥有当前背景的一致性记录时才允许生成。五题和七题旧项目按原结构读取；已确认的补充信息继续参与规划和复核，未开始的补充题不显示，未完成的补充题不阻塞生成。保留原回答、对话和草稿。整轮重新采集使用四题；单题重新回答按项目保存顺序清空本题及后续内容。

访谈只显示本题对话。自动整理复用已确认题目的原始用户消息，应用后的证据保存实际消息和来源题；AI 总结仍由用户逐题确认。跨题复用与当前题采用建议的引用规则见[Agent 接入](agents.md)。

访谈在本题确认前返回当前候选的总结和跨题一致性评估，判断用户采用候选后的完整背景。新完整回复缺少评估时进入一次协议纠正，仍缺失则拒绝，不提供可采用总结；未完成补问和旧保存候选保持兼容。共享语义规则区分冲突、待确认与兼容，不按关键词、主题数量或固定依赖表重置答案。自然细化正常继续；不清楚是补充、替换还是同时保留时，在当前题指出具体差异并只追问一项，返回未完成访谈，不提供可采用总结。当前修改是拟采用意图，已明确采用的变更是后续检查的意图依据；预算、设备、排除项和硬期限不得擅改，真实历史经验不改写成新领域经验，有意的多目标允许分阶段或分支。

当前回答涉及已确认前文的调整时，沿用本题确认卡片展示受影响题、原值、调整后内容与简短原因，提供“确认调整并继续”和“继续补充”。用户明确表达改动意图且所有事项均有完整、实际改变字段的确定建议时，确认可原子保存当前回答及全部前文调整，记录独立采用事件与来源，不伪造聊天消息或用户原话。缺建议、仍有疑问或目标不是之前已采用题时留在当前题澄清。确认后向前进入下一题，并简短提示已同步的题目；不得自动跳回旧题或把当前对话替换为旧题复核窗口。切换清单仅查看，主动重新回答仍使用清空本题及后续答案的确认流程。采用同步建议后的最终背景由后续访谈或一次生成前检查验证，不能复用检查旧背景的结论。旧项目缺检查记录时首次生成补一次检查；旧待复核事项在当前对话中标明关联题目，不切换当前问题。

一致性凭据由宿主绑定策略版本、递增backgroundEpoch及规范化已采用答案/资料说明的SHA-256；模型不生成可信哈希或版本。采用候选的评估绑定基础epoch和完整候选事实，晚到、取消、重启恢复及A→B→A改动不能复用旧结果。前后端生成门禁共用领域层；焦点、模型或智能体切换不改变答案事实。生成阶段仍发现矛盾时在当前页面显示带题号的复核卡片，不自动切换问题，原路线与历史保留，不从回复文字猜测字段。技术失败保留草稿、已采用答案和旧路线，不自动重发。

采集页只显示当前题本轮的问答；切换清单只查看其他题；重新回答经提示确认后清空目标题及后续题，之前题目与可选资料说明保留；整轮重新采集删除本轮全部题内回答、对话和资料说明。两种操作均递增背景epoch，使旧总结及晚到任务失效。旧版已完成项原样保留，新回答统一走总结采用流程。必要项全部采用后由用户点击“生成路线”，每次点击都启动新生成，不复用旧路线。修改回答且已有章节时先提示“修改问题会覆盖已生成路线，是否修改？”，取消不启动请求；运行时再次校验覆盖许可与修订。新结果完整有效后才替换旧稿并进入编辑器，同时清除旧路线的编辑对话与章节引用，保留采集问答、答案快照及证据并重映射题目对话起点；失败、中断或取消保留旧路线与旧编辑对话。撤销路线不恢复已清除的旧对话。无AI直接空白编辑；导入直接编辑已有路线。未完成草稿可保存、重开继续，但确认时必须满足正式路线契约。手动保存、AI提案采用及路线替换共用撤销/前进历史，最多20个快照、合计2MiB；旧单步撤销记录可读取并在首次操作时纳入历史。撤销和前进均生成递增的路线修订，清除待采用提案与原确认状态；撤销后新建修改清空前进分支，无内容变化的保存不改变历史。未保存编辑在撤销时先保存为一个可前进恢复的编辑批次。历史存于项目规划文件，不发给智能体；AI修改先保存独立提案，用户采用前不覆盖章节。替换已有路线须明确确认，保留新导入的原始源与可撤销的前稿。

“生成路线”打开独立过程窗口。进度条依次显示准备、总纲、小节、审核、保存，并说明当前要做的事。准备阶段核对答案和已选资料。总纲阶段确定章节层次和先修顺序。细化小节时按照已保存的批次更新节数。审核阶段复核目标、练习与验收并按问题修正。保存阶段校验完整路线、依赖与引用，保存成功后进入编辑路线。续生从已保存的阶段和节数恢复。已收到的内容和实时活动可回看，审核修正完成后展示经校验的小节正文。

总纲和通过字段与引用校验的批次保存到独立的 `generationDraft`。恢复时跳过已保存的生成批次，审核包含已保存修订的最新草稿。背景 epoch、事实哈希、语言、检查点兼容版本或原路线哈希不匹配时须重新生成。章节齐备后验证结构与依赖，审核整条路线的教学目标、实操衔接和验收。审核问题按小节分批修订，每批最多 3 节，每批校验成功后单独保存。某一批修订未通过结构校验时继续处理其他批。存在无目标的问题时，要求审核定位可修订的小节。每次运行对同一节的同类问题最多尝试两轮，新类型的问题可以继续修订。没有可保存的改动并且当前问题无法继续定位或修订时暂停。暂停、失败或取消保留原路线及修订草稿。复审通过后原子替换并进入编辑页。

生成总纲若在标题或阶段目标中使用代码标识符，先纠正总纲。课程完整后，内容审阅与本地检查一起识别用实现细节命名的学习目标。只允许修订明确标记的小节标题，保持路线身份、顺序和未受影响内容，合并后复审。暂停窗口展示一个用户可理解的主要原因、保存状态及下一步。生成记录默认收起，可主动展开回看已接收的内容；停止后的未完成输出不再标为接收中。短摘要缺失、含内部字段或语言不匹配时使用内置说明。可恢复的生成批次或审核修订均从已有草稿继续。

编辑页AI区支持普通问答与路线修改，由AI按完整上下文区分。说明、概述、比较或澄清返回`reply`及`route:null`，兼容省略`route`；不要求重写完整路线，未完成草稿也可讨论。问答不改章节、确认状态、已有提案或撤销记录。明确修改才返回完整v2路线提案，仍须用户采用；仅修订号变化不产生空提案。实际修改预览由当前路线与候选路线计算，不使用回复摘要替代。同名先修小节显示当前章序号和名称，避免变更被同名文本掩盖。仅有文字答复或返回相同路线时，由宿主保存并显示“路线未修改”，不将智能体的完成措辞作为写入凭据；普通问答仍保留之前的待采用提案。助手消息可含宿主生成的 routeEdit 记录，绑定请求修订、路线 ID、前后路线修订及忽略修订号的内容哈希；采用后用现有撤销历史恢复前后内容，避免在每条消息复制整条路线。记录不发送给智能体。历史快照已淘汰时只显示采用状态，不以其他版本冒充当次修改。旧数据无该记录仍可读取，不改写学习库。讨论区分当前路线与待采用提案。大小章菜单均可“添加到对话”，在输入框光标处插入`@第3章`或`@3.1节`，可混合引用最多32个大小章节，同一目标不重复插入。引用以`chapterId/nodeId`绑定，随用户消息持久化；重排或切换语言更新输入中的编号，改名不改变定位。章节顺序以`chapters/nodes`数组为准，编号由当前下标派生，不从ID、标题或旧编号推算；移动保持章节、目标与前置引用的稳定ID，跨大章移动小章后输入与发送引用按nodeId定位新父章。历史消息原文保留，引用展示按当前顺序更新；已删除节点不得改指同位置的新节点。删除输入中的引用文字即取消附带该内容。发送前复核当前草稿，已删除或失效的引用要求重新选择；历史消息保留原ID，不重新指向同位置的其他章节。运行时按ID读取完整大章或小章内容后附给智能体，不接受前端提供的章节正文；完整路线仍作为编辑上下文。相同正文但不同引用视为不同请求；重试沿用原引用，兼容旧单目标消息。网络失败或取消保留原消息，手动重试相同的未回复消息不重复追加；活动请求和修订保护保持有效。

请求绑定项目、ID和基础修订。活动请求不得并发覆盖；取消、失败与重启中断保留回答和旧路线，晚到结果不能提交。重启恢复不重放请求，正常页面读取不取消本进程活动任务。每条消息、历史总量、JSON大小和层级均有上限，超限不创建无法完成的任务。真实CLI接入范围与验证状态按[Agent接入](agents.md)，协议夹具验收不等于完整真实访谈验收。

## 规划与校准

先由成果及证据反推能力与先修，再组织阶段和具体活动。学习活动与目标对齐，按基础和材料安排示例、指导练习、独立尝试、解释、操作、反馈修正、跨时段复现及整合应用；交错针对相关辨别任务，不随机打乱先修。学习前不预设正式小章验收，无学后测评证据时仅记录自评或未验证。

估时包含理解、练习、修正、复现、整合和必要准备，外部等待单列。估计有依据与不确定项；目标、期限、预算或资源冲突由用户决定调整，不压缩时长或偷删必需能力制造可行性。首轮代表性任务后按实际耗时、错误、帮助需求及延迟表现校准，不承诺统一课时、复习序列、练习比例或通过率。

AI生成结果和修改均为可审阅提案，关联背景与路线基础修订，采用后提交且可撤销。AI辅助完成不等于独立掌握；评价记录使用的资料、工具及帮助条件，不凭流畅回答或模型总分推断能力。依据与适用边界见[学习计划调研](../research/learning-plan/2026-10-29.md)；本产品效果、估时及AI评价仍需实测。

## 掌握与进度

| 记录 | 含义 |
| --- | --- |
| `locked / available / in_progress / completed / mastered / skipped` | 节点活动状态 |
| `unassessed / self_reported / demonstrated` | 掌握证据类型 |
| `dueAt / lastReviewedAt` | 独立复习状态 |

已完成或手动标记为已掌握的前置小节满足解锁条件。明确指定为前置的选学小节也适用。跳过的小节可补学，或在具备相应知识时在地图标记“已掌握”。当前小节还有未满足的依赖时，信息框列出缺少的前置小节，禁用学习和掌握操作。进度规则与旧记录兼容见[学习进度契约](../contracts/learning-progress.md)。用户完成本节后，先保存正文及学习完成记录；成功返回刚完成小节所在的地图页。保存失败停留学习页并允许重试，离开页面后的迟到响应不切换用户当前页面；重新查看已完成小节不自动跳走。

证据记录 `evidenceId / nodeId / routeRevision / objectiveIds / kind / artifactRef / evaluator / result / createdAt`。AI 评价标记来源并允许复核；缺少标准或资料时不自动判定掌握。

当前必学进度 = 已完成或已掌握的必学小节数 / 必学小节总数，大章节采用相同口径。全部为选学时显示选学进度。旧路线和新小节默认必学；选学仍保留完成记录，地图推荐优先安排可学习的必学小节。不用游戏等级、浏览时长或 AI 回复数量作为掌握程度。导入空路线不进入学习状态。

编辑小节的“其他设置”提供必学／选学及“前置章节”多选。前置项按当前小节编号与名称展示，可跨大章选择，稳定 ID 随路线保存；默认无依赖。自身不可新增，会形成循环的选项不可选，旧版失效引用仍可取消。前置项增删共用路线保存、确认及撤销重做，不改变学习记录。RouteV2 使用可选 requirement（required／optional），缺省为必学；已学小节遵循同一只读保护。旧版 review（content、passCriteria）与 assessment 继续保留以便兼容，不作为新路线制定时的设置。

路线更新保留历史版本、作品与证据；删除节点从新版本分母移除，历史不丢失；未能对应的记录进入历史区。复习失败不撤回已发钱币，可改变复习计划和掌握提示。

点击“开始学习”先持久化小节的开始状态。开始、完成和“已掌握”记录均触发路线编辑保护，小节及所属大章的标题和阶段目标保持只读。路线保存、AI 提案采用、导入、重新生成和撤销重做共用该校验。仅跳过的小节保持可编辑。

小节跳过仅需确认，不要求理由；状态、旧版原因兼容和补学规则见[学习进度契约](../contracts/learning-progress.md)。地图与路线编辑器不提供清空学习记录后编辑的入口，已学保护继续适用于所有修改路径；已有记录与原件保持不变。底层清空迁移协议保留兼容，但不作为当前用户界面操作。

## 背包与工作台

- 规划问答和路线编辑的对话框可为一条消息附加多张本地图片和多个文档。附件数量由当前智能体和模型的输入能力决定。图片按当前模型的图片输入能力发送，PDF、DOCX、字幕与纯文本通过可读正文发送。已发送附件显示在对应消息中，重试时可继续发送同一份快照。规划背景以用户确认的回答为准，生成路线使用已解析的学习资料。
- 规划资料最多 20 个文件、20 条网页链接，支持多选文件和逐行粘贴 HTTP(S) 链接。每个小节背包可另加 40 个文件、20 条链接。同一来源的重复导入不占名额。
- 编辑路线的小节资料与学习页背包均可从项目资料库选择，或多选本地文件、逐行添加网页链接。小节新增资料只保存原件引用，不读取正文、不请求网页、不自动解析或转写，保存后即可打开与移除。已有的规划资料关联和摘录继续保留；同一资料可加入不同小节，移除只解除当前小节的补充引用。小节补充资料不自动加入规划参考，日后在规划资料窗口主动添加同一来源时才按规划流程解析。
- 小节网页预览按资料在当前小节或所属大章的路线关联、直接附件关系或已保存的工作台放置记录授权。已关联的网页可在工作台首次打开时直接显示。网页预览内容不会自动加入智能体对话或生成路线的参考。
- 在学习资料窗口主动发起网页搜索，使用已确认的学习方向。“开始搜索”经确认后替换本次窗口内的搜索结果。“继续搜索”保留已找到的结果并搜索其他教程。手动与搜索链接共用 20 条上限，宿主收录能读取正文或 PDF 摘录的公开教程。
- 项目资料库引用原件，分别保留来源版本、页码、段落或时间码。相同路径的文件更新后重新添加会产生新版本。旧关联保留当时的摘录，原件变动时需重新添加。可逐项勾选或全选各状态的规划资料。保存后生效的删除释放名额，保留原件并在关联章节标明资料已删除。已删链接可手动再次添加。
- 规划资料添加后立即开始解析，仍可在解析中保存。学习资料窗口暂存添加、删除与搜索结果，保存时一次更新项目清单。放弃后恢复已有清单，已保存资料的解析可以继续进行。已解析内容可在该资料下展开，失败资料保留在清单中，可在行内重试。PDF 用 PDFKit 提取并对有限扫描页使用 Vision OCR。支持 DOCX 正文、常用文本、公开静态网页和 SRT/VTT。
- 规划资料中的音视频优先读取字幕，需要时使用内置 Whisper 在本机转写可解码的首条音轨。项目资料库分段保存进度和时间码，暂停或失败后从已完成的位置继续。转写内容可在规划资料窗口查看，完成后从整条音轨取可定位的文字摘录。旧版小节媒体摘录的关联 ID 与已转写内容保留。技术与许可见 [本机转写方案](../research/local-transcription/2026-11-16.md)。
- 保存后可读的资料直接用作新路线的参考，提供受限原文片段及定位。部分可用的资料仅提供已读部分。首次生成直接开始，已有路线时先确认覆盖。生成草稿恢复沿用原快照，新增资料在重新生成时纳入，删除草稿所用资料后需重新生成。
- 总纲接收每项代表片段，细化接收与当前章目标关联的有限片段，并记录各节采用的片段。最终审核对照整条路线和各项代表片段，为尚未关联且直接支持课程的资料补上最匹配的小节或大章。运行时核对项目内版本、真实定位及目标范围，保留已有的小节关联，合并有效关联后与新路线一起提交。关联按路线及章节稳定 ID 持久化，重排或撤销恢复相应关联。学习页背包接收当节及大章关联，可额外补充资料并独立保存，无需智能体。
- 问题、笔记、回答、引用和作品绑定项目与节点。笔记是用户内容，AI 改写保留可恢复版本。
- 资料问答明确区分“资料支持”“外部补充”“尚无依据”。引用必须能回到真实来源，超出上下文范围不能假装全文已读。
- 博客、PPT、网页等生成先检测宿主能力；落入学习库的作品目录并记录来源，不自动发布、上传或运行生成代码。
- 导入内容与模型输出均为数据。预览 HTML 使用隔离容器，禁用脚本/任意网络；不执行宏、安装包或文中命令。
- 网页读取不携带登录状态，每次请求及重定向校验公共 IPv4 目的地址并固定该地址。禁止访问本机、内网和云元数据。预览只渲染文本摘录。网络限制见 [curl 参数](https://curl.se/docs/manpage.html)。

## 复习与学习依据

优先使用主动回忆、带反馈的练习、分散复习、自我解释和工作任务应用。阅读与笔记帮助组织材料，不能替代练习。

产品采用可调整的初始复习间隔，并根据回忆表现、错误类型、时间预算调整；固定间隔只是初始策略，不宣称适用于每个人的最优算法。用户可暂停、改期和关闭提醒，不以断签惩罚进度。

依据：[Dunlosky 等，2013](https://www.psychologicalscience.org/journals/pspi/1529100612453266/) 对练习测试和分散练习给出较高实用性评价；[IES 学习组织指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) 支持间隔学习、测验和深度问题。以上支持方法选择，不保证特定职业技能或个人学习效果。

## 路线分享

分享包仅含路线结构与公开学习描述。导出采用字段白名单，排除个人背景、进度、笔记、资料、路径、账号、Agent 会话及凭据。发布前展示实际包并由用户发起发布；含私人信息的自然语言需单独检查，Schema 无法识别所有敏感内容。

v1/v2路线文件是UTF-8 JSON，不接受压缩包、脚本和嵌入文件；校验大小、版本、字段、ID、目标关联和依赖DAG。未知版本停止导入，既有项目保持不变。来源不可信不妨碍阅读，但不获得执行权限。

项目列表打开按已保存步骤继续；明确点击创建路线且开启AI辅助时回到信息采集，保留旧章节直到生成新草稿，关闭AI则直接编辑。已导入路线在路线入口与编辑页提供删除确认，清除项目导入副本及其编辑草稿、提案和撤销缓存，原文件保留；独立生成的新路线不受旧导入副本删除影响。删除当前导入路线后重新打开项目回到路线来源选择，跨文件中断由读取时按导入记录清理恢复，不能重新带回已删除的路线。

路线来源石牌只选择，不立即保存或跳转。已有章节且改选创建/导入时，“下一步”先确认“已生成的路线会被覆盖，是否确定？”；取消保留保存的选择和路线，确认后再保存来源。改选导入须选择文件；改选手动创建从空稿开始，旧路线进入撤销历史。

可选资料作为规划级资源说明保存并传入规划上下文，不混入某题对话，不重置已采用回答；修改资源且已有路线时仍需确认重新生成覆盖。
