# 产品边界

## 用户与结果

服务需要持续提升工作能力的成年人。学习目标必须关联可观察的实际任务，学习路线可由 Agent 生成，也可导入他人分享的路线。游戏化反馈帮助理解进度，不代替学习证据。

## 三端职责

| 端 | 负责 | 不负责 |
| --- | --- | --- |
| 电脑本地端 | 目标访谈、路线编辑与导入、资料背包、Agent 交互、笔记、作品、学习与复习、进度持久化 | 自动公开用户资料、代购 Agent 额度 |
| 网页端 | 账号与授权门户，后续路线发现、发布、下载、版本与作者信息 | 读取电脑任意路径、执行用户电脑命令 |
| 移动端 | 配对后查看进度、阅读笔记、完成复习、离线缓存与同步 | 第一阶段完整路线编排、远程控制桌面 Agent |

Skill 提供工作流和调用约定；GUI、本地进程、数据库和动画由配套运行时提供。Skill 自身不提供模型、认证、永久后台进程或跨端同步能力。

## 已确定

- 本地优先，先 macOS，后 Windows；网页与移动端通过版本化接口扩展。
- Agent 目标：Codex、Claude Code、CodeBuddy、Qoder、OpenClaw、Hermes。能力取决于用户所用工具、版本、登录、权限与额度。
- 一期必须交付真实 AI 学习闭环，首个接入为 Codex；覆盖背景访谈、路线提案、资料问答、笔记辅助与学习成果草稿。AI 是核心能力，不能用纯手动应用替代一期交付。
- 中文 `zh-CN`、英文 `en`；界面语言和课程内容语言独立。
- 2.5D 低多边形魔法世界，金丝熊主角，小章节有明确节点与怪物。
- 所有交互文字采用可商用、可分发的黑体，当前中英文使用思源黑体 Source Han Sans CN；固定标题可采用经确认的图像文字。排版规则见 [experience](experience.md)。
- license 从第一阶段保留边界；实际价格、付费功能、设备额度、离线期限由产品策略配置，未确定前不启用真实收费。
- 账号采用CloudBase身份认证，沿用邮箱验证码注册、邮箱密码登录、邮箱验证改密/重置和激活码绑定设备；业务云函数负责权益与设备事务，客户端验签。

## 产品完整闭环

创建项目 → 简短背景访谈或导入路线 → 编辑并采用路线 → 查看地图 → 为节点导入资料 → 提问、记笔记 → 完成练习并记录证据 → 保存进度 → 击败怪物 → 安排复习。

无 Agent 时，已导入路线、本地资料、手动笔记与自评仍可用。这是故障降级；AI 生成功能显示真实不可用原因和恢复入口，未经真实 Agent 验收不得宣布一期完成。
